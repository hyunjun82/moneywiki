# 🚀 키워드 수집기 사용 가이드

## 📋 기능

### 5개 소스 통합 수집
1. **네이버 연관검색어** (30~50개)
2. **구글 연관검색어** (30~50개)
3. **빙 연관검색어** (20~30개)
4. **다음 연관검색어** (20~30개)
5. **구글 PAA 무한 확장** (40~100개)

### 자동 처리
- ✅ 중복 제거 (동의어 그룹 활용)
- ✅ 관련없는 키워드 배제
- ✅ Hub/Spoke 분류
- ✅ CSV + JSON 저장

---

## 🎯 사용 방법

### 기본 사용
```bash
py .claude/scripts/collect-all-keywords-full.py "퇴직금"
```

### PAA 수집 개수 지정
```bash
py .claude/scripts/collect-all-keywords-full.py "근로장려금" 150
```

## 🔍 관련없는 키워드 배제 로직


## 🎯 중복 제거 (동의어 그룹)

### 동의어 그룹
```yaml
신청 ≈ 가입 ≈ 접수 ≈ 등록
조건 ≈ 자격 ≈ 요건 ≈ 대상 ≈ 기준
방법 ≈ 절차 ≈ 안내 ≈ 신청법
기한 ≈ 기간 ≈ 시기 ≈ 일정
금액 ≈ 비용 ≈ 가격 ≈ 수수료
```

### 중복 제거 예시
```
원본 (243개):
- "퇴직금 신청 조건" (네이버)
- "퇴직금 가입 자격" (구글) ← 중복!
- "퇴직금 접수 요건" (다음) ← 중복!
- "퇴직금 등록 대상" (빙) ← 중복!

중복 제거 후 (178개):
- "퇴직금 신청 조건" (네이버,구글,다음,빙)
```

**하나로 통합되고, 소스는 모두 기록됩니다!**

## 📊 활용 방법

### 1. 엑셀에서 분석
```
1. 퇴직금-all.csv 파일 열기
2. "분류" 열 기준 정렬
3. Hub 키워드만 필터링
4. 타이틀 생성에 활용
```

### 2. /keyword 명령어 연계
```bash
# CSV 확인 후
/keyword 퇴직금

# JSON 읽어서 타이틀 생성
→ 퇴직금-titles.yaml (20개 타이틀)
```

### 3. /wiki-orchestra 연계
```bash
/wiki-orchestra 퇴직금

# titles.yaml 읽어서 위키 글 작성
→ content/wiki/*.md (20개 파일)
```

```bash
pip install playwright
playwright install chromium

```

---

### 구글 차단 (Captcha)
**증상:** "로봇이 아닙니다" 화면

**해결:**
```python
# 스크립트 수정: 딜레이 증가
time.sleep(random.uniform(2.0, 4.0))  # 기존 1~2초 → 2~4초
```

---

### CSV 한글 깨짐
**증상:** 엑셀에서 한글이 깨짐

**해결:**
- 이미 UTF-8 BOM으로 저장 중
- 엑셀 2016 이상 사용
- 또는 구글 스프레드시트로 열기
