## 글 작성 체크 (10개마다 점검)

### 필수 확인
- [ ] 구어체? (~이에요, ~해요)
- [ ] 테이블 2개 이하?
- [ ] 각 섹션 4문장 이상?
- [ ] H2에 베이스 키워드?

### 절대 금지
- 이모지
- 숫자 헤딩 (`## 1.`)
- 본문 FAQ 섹션
- "~알아봅니다" description

---

## 규칙 위반 자가 진단

### 징후
1. 테이블이 3개 이상 → 텍스트로 변환
2. "~습니다" 문장 → "~이에요" 로 변환
3. 섹션이 2문장 → 4문장 이상 보충
4. H2가 질문형 아님 → 질문형으로 수정

### 발견 시
- 해당 글 전체 재작성
- 이전 10개 글 점검

---

## 배치 작성 워크플로우

```
1. 키워드 10개 단위로 작성
2. 10개 완료 → 규칙 점검
3. 위반 발견 → 즉시 중단 + 수정
4. 다음 10개 진행
5. 반복
```
