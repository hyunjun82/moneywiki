- `/wiki`

- "이어진행해줘"
- "이어서 작업해줘"

---

## 실행 시 자동 동작

### 1단계: 상태 파일 읽기
```
Read(".claude/state/moneywiki-orchestra.yaml")
```

### 2단계: 현재 상태 확인
- 상태 파일 없음 → 새 프로젝트 시작 (키워드 요청)
- 상태 파일 있음 → 마지막 작업 이어서 진행

### 3단계: 자동 진행
- pending 작업 있으면 → 자동 실행
- 완료된 작업 있으면 → 상태 요약 출력

---

## 상태 파일 자동 업데이트

| 시점 | 저장 내용 |
|------|----------|
| 글 1개 완료 | status: completed |
| 썸네일 완료 | thumbnail: true |
| git push 완료 | git_pushed: true |
| 에러 발생 | errors 배열에 기록 |

---

## 필수 참조 파일

작업 시 반드시 읽어야 할 파일:
1. `.claude/references/keyword-skill.md` - 키워드 추출 규칙
2. `.claude/references/moneywiki-template.md` - 글 작성 템플릿
3. `.claude/references/chart-template-guide.md` - 차트 규칙
4. `.claude/references/thumbnail-workflow.md` - 썸네일 절차

## 자동 검증 체크리스트

글 완료 전 반드시 체크 (하나라도 빠지면 자동 수정):

### 필수 항목
- [ ] 키워드 4개 = H2 4개 일치?
- [ ] 모든 H2에 베이스 키워드 포함?
- [ ] 각 섹션 4문장 이상?
- [ ] 구어체 (~이에요, ~해요)?
- [ ] 내부링크 3개 이상?
- [ ] 출처 섹션 (본문 인라인 + 하단)?
- [ ] FAQ 2개 (소제목과 안 겹침)?
- [ ] 테이블 2개 이하?
- [ ] CTA 버튼 있음?
- [ ] chart + chartConfig 있음?
- [ ] thumbnail 필드 있음?

### 금지 사항
- [ ] 이모지 없음?
- [ ] 숫자 헤딩 없음 (## 1. 제목)?
- [ ] 본문 FAQ 섹션 없음?
- [ ] "~알아봅니다" 없음?
