# 슈퍼 롱테일 키워드 생성기

입력: 시드 키워드 1개
출력: 타이틀 + 키워드 4개 + H2 4개

---

## ⛔ 강제 규칙

### 규칙 1: 동의어 동사 금지 (2x2 불가!)
```
가입 ≈ 신청 ≈ 접수 ≈ 등록 → 같은 행위!
확인 ≈ 조회 ≈ 검색 ≈ 찾기 → 같은 행위!
해지 ≈ 탈퇴 ≈ 취소 ≈ 해약 → 같은 행위!
```

### 규칙 2: 동의어 측면 금지 (같은 질문!)
```
누가?: 자격 ≈ 조건 ≈ 요건 ≈ 대상 ≈ 기준 ≈ 나이 ≈ 소득
어떻게?: 방법 ≈ 절차 ≈ 안내
언제?: 기간 ≈ 기한 ≈ 시기
얼마?: 금액 ≈ 비용 ≈ 가격 ≈ 혜택 ≈ 지원금
무엇?: 서류 ≈ 준비물 ≈ 문서
```

### 규칙 3: 2x2 vs 1x4 판단
```
2x2: 동사 2개가 완전히 다른 행위
  ✅ 신고 ≠ 납부 (제출 vs 돈냄)
  ✅ 신청 ≠ 만기 (시작 vs 끝)

1x4: 동사가 동의어일 때
  → 하나의 동사 + 4개 다른 질문
```

### 규칙 4: Filler 금지
```
❌ ~총정리, ~완벽정리, ~정리, ~알아보기
```

## 실행 순서

### 1단계: 실제 검색 데이터 수집 (필수!)
```
시드 키워드로 WebSearch 실행:
1. 네이버 연관검색어 (site:naver.com)
2. 구글 연관검색어 (자동수집)
3. 구글 PAA (People Also Ask)
4. 다음 연관검색어 (site:daum.net)
5. 빙 연관검색어 (site:bing.com)

⚠️ 실제 검색 결과에서 추출한 키워드만 사용!
⚠️ 추측/생성 키워드 = 훅에서 차단!
```

### 2단계: 키워드 필터링
```
수집된 키워드에서:
- 동의어 제거 (가입=신청, 조건=자격)
- 4개 질문으로 분류 (누가/어떻게/언제/얼마)
- 검색량 높은 것 우선
```

### 3단계: 2x2 vs 1x4 판단
### 4단계: 타이틀 + 키워드 생성
### 5단계: 동의어 체크 → 위반 시 재생성
### 6단계: 출력

## 타이틀 패턴

| 패턴 | 예시 |
|------|------|
| {K1}과 {K2} | 법인세 신고 기한과 납부 방법 |
| {연도}년 {K1}과 {K2} | 2026년 법인세 신고 기한과 납부 방법 |
| {K1} 및 {K2} | 희망저축계좌2 신청 조건 및 만기 혜택 |

---

## H2 = 키워드 + 질문

| 키워드 끝말 | 질문 |
|------------|------|
| 방법, 절차 | ~은 어떻게 되나요? |
| 금액, 이자, 혜택 | ~은 얼마인가요? |
| 기한, 기간 | ~은 언제인가요? |
| 조건, 자격 | ~은 어떻게 되나요? |
| 서류 | ~은 무엇인가요? |

---

## 좋은 예시: 2x2 (법인세)

```yaml
# 신고 ≠ 납부 ✅ (다른 행위)
title: "법인세 신고 기한과 납부 방법"

keywords:
  - 법인세 신고 기한
  - 법인세 납부 방법
  - 법인세 신고 방법
  - 법인세 납부 기한

h2:
  - 법인세 신고 기한은 언제인가요?
  - 법인세 납부 방법은 어떻게 되나요?
  - 법인세 신고 방법은 어떻게 되나요?
  - 법인세 납부 기한은 언제인가요?
```

## 좋은 예시: 2x2 (희망저축계좌2)

```yaml
# 신청 ≠ 만기 ✅ (시작 vs 끝)
title: "희망저축계좌2 신청 조건과 만기 혜택"

keywords:
  - 희망저축계좌2 신청 조건
  - 희망저축계좌2 만기 혜택
  - 희망저축계좌2 신청 방법
  - 희망저축계좌2 만기 조건

h2:
  - 희망저축계좌2 신청 조건은 어떻게 되나요?
  - 희망저축계좌2 만기 혜택은 얼마인가요?
  - 희망저축계좌2 신청 방법은 어떻게 되나요?
  - 희망저축계좌2 만기 조건은 어떻게 되나요?
```

## 나쁜 예시 (절대 금지!)

```yaml
❌ "디딤씨앗통장 가입 조건과 신청 방법"
→ 가입 ≈ 신청 = 같은 행위!

❌ 키워드: 자격 조건, 자격 나이, 자격 소득, 자격 기준
→ 조건 ≈ 나이 ≈ 소득 ≈ 기준 = 전부 "누가?" 질문!

❌ "~총정리", "~완벽정리"
→ SEO 가치 없는 filler!
```

## 체크리스트

```
□ 동사A ≠ 동사B? (동의어 아닌지)
□ 측면 4개가 4개 다른 질문?
□ filler 없음?
□ 2x2 불가능하면 1x4?
```
