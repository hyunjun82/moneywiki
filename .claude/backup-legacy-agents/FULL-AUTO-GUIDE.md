# 🚀 머니위키 풀자동화 가이드

## 3단계 명령어로 20개 위키 글 자동 생성

```bash
/paa 근로장려금        # 1단계: 100~200개 키워드 수집
/keyword 근로장려금    # 2단계: 20개 타이틀 생성
/wiki-orchestra 근로장려금  # 3단계: 20개 위키 글 작성
```

---

## 📋 전체 프로세스

### 1단계: PAA + 연관검색어 수집 (5분)

```bash
/paa 근로장려금
```

**자동 실행:**
1. 네이버 연관검색어 수집 (30~50개)
2. 구글 연관검색어 수집 (30~50개)
3. 다음 연관검색어 수집 (20~30개)
4. 빙 연관검색어 수집 (20~30개)
5. 구글 PAA 수집 (40~100개)
6. 중복 제거 (동의어 그룹 활용)
7. Hub/Spoke 분류

**출력:**
```
[1/5] 네이버 45개 ✓
[2/5] 구글 42개 ✓
[3/5] 다음 28개 ✓
[4/5] 빙 25개 ✓
[5/5] PAA 87개 ✓

중복 제거: 227개 → 156개
Hub: 12개, Spoke: 144개

✅ 저장: 근로장려금-all.json
```

**저장 위치:**
`.claude/data/paa-results/근로장려금-all.json`

---

### 2단계: 롱테일 타이틀 생성 (3분)

```bash
/keyword 근로장려금
```

**자동 실행:**
1. `근로장려금-all.json` 읽기
2. Hub 키워드 12개 선택
3. 각 Hub별 타이틀 생성 (2x2 or 1x4)
4. 키워드 4개 + H2 4개 생성
5. 동의어 검증
6. YAML 파일 저장

**출력:**
```yaml
titles:
  - title: "2026 근로장려금 신청 조건과 소득 기준"
    keywords: [...]
    h2: [...]
  
  - title: "근로장려금 지급 시기와 조회 방법"
    keywords: [...]
    h2: [...]
  
  ... (총 12~20개)
```

**저장 위치:**
`.claude/state/근로장려금-titles.yaml`

---

### 3단계: 위키 글 자동 작성 (20분)

```bash
/wiki-orchestra 근로장려금
```

**자동 실행:**
1. `근로장려금-titles.yaml` 읽기
2. 각 타이틀별 서브에이전트 소환
   - **moneywiki-writer**: 글 작성
   - **moneywiki-reviewer**: 검증 + 자동 수정
   - **validator**: 16-Point 검증
3. `content/wiki/*.md` 파일 생성

**출력:**
```
[1/20] 근로장려금-신청-조건.md ✓ (검증 통과)
[2/20] 근로장려금-지급-시기.md ✓ (검증 통과)
[3/20] 근로장려금-소득-기준.md ✓ (검증 통과)
...
[20/20] 근로장려금-반기-신청.md ✓ (검증 통과)

✅ 20개 위키 글 작성 완료!

다음 단계: git add && git commit && git push
```

**생성 파일:**
`content/wiki/근로장려금-*.md` (20개)

---

## 📊 각 단계별 세부 정보

### 1단계: `/paa` 상세

| 소스 | 수집 개수 | 수집 방법 |
|------|-----------|-----------|
| 네이버 | 30~50개 | Playwright (연관검색어 영역) |
| 구글 | 30~50개 | Playwright (관련 검색 영역) |
| 다음 | 20~30개 | Playwright (연관검색어 영역) |
| 빙 | 20~30개 | Playwright (관련 검색 영역) |
| PAA | 40~100개 | Python (V 버튼 20회 클릭) |

**중복 제거 규칙:**
```yaml
동의어 그룹:
  - [신청, 가입, 접수, 등록]
  - [조건, 자격, 요건, 대상, 기준]
  - [방법, 절차, 안내, 신청법]
  - [기한, 기간, 시기, 일정]

예시:
"근로장려금 신청 조건" ✓
"근로장려금 가입 자격" ✗ (중복 제거)
```

**Hub/Spoke 분류:**
```yaml
Hub (베이스 키워드 포함):
  - "근로장려금 신청 조건은?"
  - "근로장려금 지급 시기는?"

Spoke (관련 키워드):
  - "근로장려금 소득 기준"
  - "근로장려금 반기 신청"
```

---

### 2단계: `/keyword` 상세

**타이틀 패턴 (10가지):**

| # | 패턴 | 예시 |
|---|------|------|
| 1 | {K1}과 {K2} | 근로장려금 신청 조건과 소득 기준 |
| 2 | {K1}, {K2}, {K3} | 근로장려금 신청, 조회, 지급 시기 |
| 3 | {연도}년 {K1}과 {K2} | 2026년 근로장려금 신청 조건과 소득 기준 |
| 4 | {K1}부터 {K2}까지 | 근로장려금 신청부터 지급까지 |
| 5 | {K1} 시 {K2} 주의사항 | 근로장려금 신청 시 소득 기준 주의사항 |
| 6 | {K1} 전 알아야 할 {K2} | 근로장려금 신청 전 알아야 할 서류 |
| 7 | {K1}과 {K2} 차이 | 근로장려금 정기와 반기 차이 |
| 8 | {K1}, 언제 어떻게? | 근로장려금 신청, 언제 어떻게? |
| 9 | {K1} 및 {K2} | 근로장려금 신청 방법 및 필요 서류 |
| 10 | {K1}할 때 {K2} 확인 | 근로장려금 신청할 때 소득 기준 확인 |

**키워드 → H2 변환:**

| 키워드 끝말 | H2 질문 패턴 |
|------------|-------------|
| 절차, 방법 | ~은 어떻게 되나요? |
| 이자, 금액, 세율 | ~은 얼마인가요? |
| 기한, 기간, 시기 | ~은 언제인가요? |
| 기준, 조건, 자격 | ~은 어떻게 되나요? |
| 서류, 준비물 | ~은 무엇인가요? |

---

### 3단계: `/wiki-orchestra` 상세

**서브에이전트 역할:**

| 에이전트 | 역할 | 실행 순서 |
|----------|------|-----------|
| **writer** | 글 작성 + WebFetch | 1번 |
| **reviewer** | 검증 + WebSearch + 자동 수정 | 2번 |
| **validator** | 16-Point 검증 | 3번 |

**검증 항목 (16-Point):**

1. keywords 4개
2. summary 3줄
3. FAQ 2개
4. FAQ-H2 중복 없음
5. 출처 1개 이상
6. description 구어체
7. H2 개수 = keywords 개수
8. 모든 H2에 베이스 키워드 포함
9. 섹션당 4문장 이상
10. 내부링크 3개 이상
11. ## 출처 섹션 존재
12. 구어체 (~이에요, ~해요)
13. 이모지 없음
14. 숫자 헤딩 없음
15. 본문 FAQ 섹션 없음
16. 테이블 2개 이하

## 🔧 트러블슈팅

### PAA 수집 실패

**증상:** PAA 4개만 수집됨

**해결:**
```bash
# Python 스크립트 직접 실행
py .claude/scripts/collect-paa.py "근로장려금" --no-cache

# Playwright 설치 확인
pip install playwright
playwright install chromium
```

---

### 타이틀 생성 실패

**증상:** PAA 파일을 못 찾음

**해결:**
```bash
# 파일 존재 확인
ls .claude/data/paa-results/근로장려금-all.json

# 없으면 1단계부터 다시
/paa 근로장려금
```

---

### 위키 글 검증 실패

**증상:** 16-Point 검증 FAIL

**해결:**
- reviewer 에이전트가 자동으로 수정
- 3회 재시도 후 실패 시 사용자에게 보고
- 오류 로그: `.claude/state/failed-wiki-validations.log`
