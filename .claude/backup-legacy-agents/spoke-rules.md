# 스포크 글 작성 규칙서

> writer.md와 중복되는 기본 규칙(컴포넌트 API, 문체, 고유성, 금지)은 여기 없음.

## 1. 도입부 5유형 (hero.intro)

같은 허브 내 스포크끼리 같은 유형 금지. 3줄 필수 + 4줄째 선택.

**A. 상황 공감형**
```
퇴직했는데 회사가 퇴직금을 한참 뒤에 줬어요. 억울하잖아요.
14일 넘기면 연 20% 이자를 추가로 받을 수 있어요.
계산법부터 청구 절차까지 알려드릴게요.
```

**B. 숫자 충격형**
```
퇴직금 1,000만 원을 30일 늦게 받으면 약 16만 원 더 받아요.
연 20%라는 지연이자가 자동으로 붙거든요.
내 경우엔 얼마인지 아래에서 바로 계산해 보세요.
```

**C. 오해 교정형**
```
"자진퇴사하면 실업급여 못 받는다"고 알고 계시죠? 꼭 그렇진 않아요.
임금체불이나 직장 내 괴롭힘 때문에 그만뒀다면 받을 수 있어요.
정당한 이직 사유 7가지를 정리했어요.
```

**D. 비교 선택형**
```
전세 vs 월세, 지금은 뭐가 유리할까요?
금리 3.5% 기준으로 전세가 2억이면 월세 환산 58만 원이에요.
보증금 여력에 따라 답이 달라지는데, 아래에서 비교해 보세요.
```

**E. 스토리형**
```
지인이 국민연금 추납을 1년 미루다가 월 12만 원을 더 냈어요.
추납 보험료는 매년 오르거든요. 빨리 할수록 이득이에요.
신청 조건부터 납부 금액까지 순서대로 정리했어요.
```

**배분**: A→B→C→D→E 순환. 같은 유형 연속 금지.

**4줄째 (선택)**: "먼저 ~부터 볼게요." 같은 동행 톤. 형제와 겹치면 FAIL.

**금지 표현**: "~하고 계신가요?", "이 글 하나로 정리했어요", "~시달리고 있다면", "오늘은 ~에 대해", "많은 분들이"

## 2. 문체 좋은 예 / 나쁜 예

```
BAD: "간이세액표는 국세청이 발표하는 표입니다. 이 표는 매년 고시됩니다."
GOOD: "국세청이 매년 발표하는 기준표예요. 회사는 이 표대로 원천징수해요."

BAD: "80%를 선택하면 적게 떼입니다. 100%를 선택하면 기본입니다. 120%를 선택하면 많이 떼입니다."
GOOD: "어떤 비율을 골라도 연간 세금 총액은 같아요. 차이는 매달 미리 내는 금액뿐이에요."
```

금지 패턴:
- 같은 문장 구조 3회 이상 반복 ("X하면 Y해요" 반복)
- 같은 시작어 3회 이상 ("참고로~", "특히~")

## 3. 섹션 전환 5스타일

모든 섹션 끝에 전환 필수. 4개 섹션이 같은 패턴이면 FAIL. 3가지 이상 섞기.

| 스타일 | 패턴 | 예시 |
|--------|------|------|
| A. 독자 대변형 | "~싶잖아요" | "내 월급에선 정확히 얼마인지 계산해 보고 싶잖아요." |
| B. 호기심형 | "~궁금한 게 생기죠" | "여기까지 보면 한 가지 궁금한 게 생기죠." |
| C. 간결 연결형 | "~넘어갈게요" | "금액을 알았으니 자격 요건으로 넘어갈게요." |
| D. 화제 전환형 | "~주의할 게 있어요" | "그런데 한 가지 주의할 게 있어요." |
| E. 실용 연결형 | "~정리했어요" | "비율까지 정했으면 실수령액을 정리했어요." |

금지: "그렇다면 X는 Y일까요?" (글 전체 최대 1회), "~ 볼 차례예요", "다음으로 ~ 알아볼게요"

## 4. bridgeCTA href 규칙

- `href`는 반드시 `/w/슬러그` 형식. 앵커(`#sec-xxx`) 절대 금지.
- 마지막 섹션 → 허브/계산기 URL로 연결
- 기계적 질문 반복 금지 ("~알고 싶다면?" 4번 = FAIL)

---

## 5. SpokeLinks 연결 대상 선택

```
1순위: 같은 허브 내 형제 스포크 (가장 자연스러움)
2순위: 부모 허브 (전체 가이드로 안내)
3순위: 다른 허브의 스포크 (주제적 연관이 있을 때만)
금지: 실존하지 않는 슬러그, 같은 글 자기 자신
```

## 6. 인라인 내부링크 (나무위키 방식)

본문에서 형제 스포크 키워드가 자연스럽게 언급될 때 `<a href="/w/슬러그">키워드</a>` 연결.

```
규칙:
- 스포크당 최소 2개, 최대 5개
- 같은 슬러그 반복 링크 금지 — 첫 등장에만
- 같은 허브 내 형제 스포크 + 부모 허브만 대상
- 실존 슬러그만 (Glob 확인)
```

## 7. relatedSpokes 선택 기준

```
1. 같은 허브 내 형제 스포크 중 2~4개
2. 우선순위:
   - 독자가 자연스럽게 궁금해할 주제
   - 이 글에서 언급했지만 자세히 안 다룬 주제
   - 결론에서 "다음 단계"에 해당하는 주제
3. 실존하지 않는 스포크 연결 금지
```

## 10. Description 패턴 상세

```
A. 놀라움형: "[구체 사실]~라는 거 아시나요? [키워드] 알려드려요"
B. 문제해결형: "[고민] 고민이시죠? [키워드] 방법을 알려드려요"
C. 숫자형: "[숫자]~라는 사실, 알고 계셨나요? [키워드] 정리해드려요"
```

배분: 스포크 1~3 A, 4~6 B, 7~8 C, 9개 이상 순환.
