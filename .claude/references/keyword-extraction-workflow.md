# 키워드 추출 워크플로우 (PAA 기반)

## 1단계: 구글 PAA 수집

```
1. 구글에 베이스 키워드 검색 (예: "가처분 신청")
2. "관련 질문" 섹션에서 V 클릭
3. 무한 확장 → 50~100개 수집
4. 전체 복사해서 Claude에게 전달
```

---

## 2단계: 필터링 규칙

### 제외 대상
- **중복**: "가처분 얼마나 걸리나요?" = "가처분 신청 기간?" (같은 의도)
- **무관**: 베이스 키워드와 관련 없음 (이혼, 형사재판 등)
- **너무 광범위**: "변호사 비용" (특정 키워드 없음)

### 포함 대상
- **베이스 키워드 포함**: "가처분 신청 비용", "가처분 효력"
- **검색 의도 다름**: 비용/기간/절차/효력 (각각 다른 글)
- **롱테일**: 3단어 이상

---

## 3단계: 그룹핑

### 예시: "가처분 신청" PAA 정리

**그룹 A: 가처분 신청 (일반)**
```
- 가처분 신청 비용은 얼마인가요?
- 가처분 신청은 어디에 해야 하나요?
- 가처분 얼마나 걸리나요?
- 가처분 결정은 언제 나오나요?
```

**그룹 B: 가처분 효력**
```
- 가처분의 효력은 언제 발생하나요?
- 가처분신청의 효력은 무엇인가요?
- 가처분 집행 기한은 얼마나 되나요?
```

**그룹 C: 부동산처분금지가처분**
```
- 부동산처분금지가처분은 어떤 경우에 신청?
- 부동산처분금지가처분 신청비용?
- 부동산처분금지가처분 인지대는?
```

**그룹 D: 기타 가처분**
```
- 가처분 항고 기간?
- 가처분 신청 기각 뜻?
- 효력정지 가처분 신청이란?
- 접근금지가처분 효력기간?
```

## 4단계: 완성품 구조화

### 템플릿
```yaml
# 글 1
title: "[베이스] [핵심 키워드]: [부가 정보]"
keywords: [PAA 질문에서 추출한 4개]
H2 소제목: [PAA 질문 4개 그대로]
description: "~해요 패턴"
category: "카테고리"
slug: "베이스-핵심-키워드"
```

### 예시: 가처분 신청 비용
```yaml
title: "가처분 신청 비용: 인지대 담보금 변호사 수임료 총정리"

keywords:
  - 가처분 신청 비용
  - 가처분 인지대
  - 가처분 담보금
  - 가처분 변호사 비용

H2 소제목:
  ## 가처분 신청 비용은 얼마인가요?
  ## 가처분 인지대는 얼마인가요?
  ## 가처분 담보금은 얼마나 내야 하나요?
  ## 가처분 변호사 비용은 얼마인가요?

description: "가처분 신청하려는데 비용이 얼마나 드는지 궁금하시죠? 인지대, 담보금, 변호사 수임료까지 총비용 알려드려요"

category: "법률"
slug: "가처분-신청-비용"
```

## 5단계: 에이전트 분배

```
총 20개 완성품 → 5개 에이전트 × 4개씩

에이전트 1: 가처분 신청 일반 (비용, 절차, 기간, 결정)
에이전트 2: 가처분 효력 (발생, 기한, 종류, 소멸)
에이전트 3: 부동산처분금지가처분 (신청, 비용, 효력, 사례)
에이전트 4: 기타 가처분 (항고, 기각, 접근금지, 효력정지)
에이전트 5: 추가 롱테일 (PAA에서 더 발굴)
```

## 프롬프트 템플릿

### 키워드 추출 요청
```
다음 PAA 질문들을 분석해서:

1. 중복 제거 (검색 의도 같으면 하나만)
2. 무관한 것 제외 (베이스 키워드 없으면)
3. 그룹핑 (주제별)
4. 완성품 구조화 (타이틀 + 키워드 4 + H2 4 + description)

[PAA 질문 붙여넣기]
```

### 글 작성 요청
```
다음 완성품 구조로 글 작성해줘.
반드시 moneywiki-template.md 읽고 규칙 지켜서.

[완성품 구조 붙여넣기]
```

## 품질 체크

### 필터링 후 확인
- [ ] 모든 키워드에 베이스 포함?
- [ ] 검색 의도 다 다름?
- [ ] 중복 없음?

### 구조화 후 확인
- [ ] 타이틀에 베이스 + 핵심 키워드?
- [ ] keywords 4개 서로 다름?
- [ ] H2가 실제 PAA 질문?
- [ ] description이 구어체?
