## 실업급여 고용보험 가입기간, 얼마나 돼야 하나요?

**고용보험에 180일 이상 가입**되어 있어야 해요. 정확히는 "퇴직 전 18개월 동안 피보험 단위기간이 180일 이상"이에요.

**180일 계산법**: 주 5일 근무면 한 달에 약 22일이에요. 180일 ÷ 22일 = 약 8개월. 주 6일 근무면 약 7개월이에요. 휴일, 휴가도 유급이면 포함돼요.

**주의**: 단순히 근무 기간이 아니라 **고용보험료를 낸 기간**이에요. 4대보험 없이 일했으면 해당 안 돼요.

**여러 직장 합산 가능**: A회사 3개월, B회사 4개월 이렇게 해도 합쳐서 180일 넘으면 돼요. 단, 이전에 실업급여 받았으면 그 이후 기간만 계산해요.

**내 가입기간 확인**: [고용24](https://www.ei.go.kr)에서 "피보험자격 이력내역" 조회하면 정확히 나와요. 공인인증서나 간편인증으로 로그인하면 돼요.

## 실업급여 퇴직 사유, 어떤 경우에 받을 수 있나요?

**비자발적으로 퇴사**해야 해요. 내가 원해서 그만둔 게 아니라 어쩔 수 없이 퇴직한 경우예요.

"내 경우가 해당되나?" 아래 표에서 확인하세요.

| 퇴직 사유 | 수급자격 | 비고 |
|----------|:-------:|------|
| 권고사직 | O | 회사에서 퇴직 권유 |
| 계약만료 | O | 계약직 기간 종료 |
| 정리해고 | O | 회사 경영상 이유 |
| 회사 폐업 | O | 회사가 문 닫음 |
| 임금체불 퇴사 | O | 2개월 이상 급여 못 받음 |
| 직장 내 괴롭힘 퇴사 | O | 증빙 필요 |
| 통근 곤란 퇴사 | O | 왕복 3시간 이상 |
| 건강 문제 퇴사 | O | 의사 소견서 필요 |
| 단순 이직 목적 퇴사 | X | 더 좋은 곳 가려고 |
| 무단결근 해고 | X | 본인 귀책사유 |

**자발적 퇴사도 되는 "정당한 사유" 상세:**
- **임금체불**: 2개월 이상 급여를 못 받은 경우. 급여명세서, 통장 내역 준비하세요.
- **직장 내 괴롭힘**: 상사나 동료에게 괴롭힘당한 경우. 녹취, 메시지 캡처 등 증빙 필요해요.
- **통근 곤란**: 회사 이전으로 왕복 3시간 이상 걸리게 된 경우. 주소 변경 증빙 필요해요.
- **건강 문제**: 업무 수행이 어려운 질병/부상. 의사 소견서 필수예요.
- **가족 간병**: 부모님이나 자녀 간병이 필요한 경우. 진단서 필요해요.

**퇴직 사유는 이직확인서에 기재돼요**: 회사가 퇴직 후 10일 이내에 고용센터에 제출해요. 고용24에서 제출 여부와 내용 확인 가능해요. 사유가 "자발적 퇴사"로 잘못 기재됐으면 고용센터에 정정 요청하세요.

## 실업급여 자격 조건, 구직 의사도 필요해요

**적극적으로 일자리를 찾을 의사**가 있어야 해요. 실업급여는 일자리를 찾는 동안 생활을 지원하는 거예요. 그냥 쉬려고 받는 게 아니에요.

**구직활동은 4주마다 1회 이상** 해야 해요. 실업인정일에 고용센터에서 확인해요. 안 하면 그 기간 급여가 안 나와요.

**구직활동으로 인정되는 것:**
- 입사지원 (워크넷, 사람인, 잡코리아 등)
- 면접 참여
- 직업훈련 수강
- 취업특강/박람회 참여
- 고용센터 상담

**구직활동 증빙**: 입사지원 캡처, 면접 확인서, 교육 수료증 등 증빙 자료 준비하세요. 워크넷에서 입사지원하면 자동으로 기록돼서 편해요.

## 실업급여 수급자격 안 되는 경우예요

아래에 해당하면 실업급여를 **못 받아요**. 내가 해당되는지 확인하세요.

**1. 단순 이직 목적의 자발적 퇴사**

"더 좋은 회사 가려고", "연봉 올리려고" 그만뒀으면 안 돼요. 다음 회사가 정해져 있든 아니든, 본인이 원해서 그만둔 거면 수급자격이 없어요.

**2. 중대한 귀책사유로 해고**

본인 잘못으로 해고됐으면 안 돼요. 이런 경우가 해당돼요:
- 무단결근 (정당한 사유 없이 7일 이상)
- 횡령, 배임, 절도
- 회사 기밀 유출
- 고의적인 업무 방해
- 폭행, 성희롱 등 범죄행위

**3. 고용보험 미가입**

4대보험 없이 일했으면 고용보험료를 안 낸 거니까 수급자격이 없어요. 이런 경우가 해당돼요:
- 프리랜서 (사업소득으로 신고)
- 일용직 (고용보험 미가입 사업장)
- 특수고용직 일부 (예전에는 미가입, 최근 가입 확대 중)

**4. 기타 제외 대상**
- 65세 이후에 새로 고용된 경우
- 공무원, 사립학교 교직원 (별도 연금 적용)
- 1개월 미만 초단기 근로자 (일부 예외)

**"내가 해당되나?" 애매하면**: 고용센터에 먼저 상담하세요. 수급자격 신청 전에 확인받을 수 있어요.

## 내 수급자격 확인하는 방법이에요

신청 전에 미리 확인할 수 있어요. 아래 체크리스트로 먼저 판단해보세요.

**자가 체크리스트:**

| 항목 | 확인 방법 |
|------|----------|
| 고용보험 180일 이상 가입? | [고용24](https://www.ei.go.kr) 이력 조회 |
| 비자발적 퇴사 또는 정당한 사유? | 이직확인서 확인 |
| 재취업 의사 있음? | 구직활동 가능 여부 |
| 65세 미만? | 퇴직 시점 기준 |

**고용24에서 확인하는 방법:**
1. [고용24](https://www.ei.go.kr) 접속
2. 공인인증서/간편인증 로그인
3. "개인서비스" → "피보험자격 이력내역" 클릭
4. 고용보험 가입 기간 확인

**이직확인서 확인:**
- 퇴직 후 10일 이내에 회사가 고용센터에 제출해요
- 고용24에서 제출 여부와 내용 확인 가능해요
- 사유가 잘못 기재됐으면 정정 요청하세요

## 수급자격 되면 다음 단계예요

수급자격이 되면 이제 신청하면 돼요.

**얼마나 받아요?** 퇴직 전 평균임금의 60%예요. 2026년 기준 1일 최대 68,100원, 최소 66,048원이에요. [실업급여 계산기](/w/실업급여-계산기)에서 예상 금액 확인해보세요.

**얼마나 오래 받아요?** 나이와 가입기간에 따라 120일~270일까지 달라요. 50세 이상이거나 장애인이면 더 오래 받을 수 있어요.

**어디서 신청해요?** 관할 고용센터에 방문하거나 [고용24](https://www.ei.go.kr)에서 온라인 신청해요. 자세한 방법은 [실업급여 신청방법](/w/실업급여-신청방법)에서 확인하세요.

## H2~H3 구조 규칙 (나무위키식)

### H2 소제목 (3-4개 권장)
- **keywords 활용** 롱테일 검색어 포함
- **독자 질문 형태** 또는 **핵심 정보**

**⚠️ "~란" 사전식 금지 → 궁금증 해결형으로!**
```markdown
❌ ## 국민성장펀드 소득공제란 (사전식 = PAA 노출 어려움)
✅ ## 국민성장펀드 소득공제, 얼마나 받을 수 있나요? (궁금증 해결 = PAA 노출)

❌ ## 퇴직금 지연이자란 (뭔지만 설명)
✅ ## 퇴직금 지연이자 20% 계산법 (어떻게 계산? 해결)

❌ ## 전입신고란 (정의만)
✅ ## 전입신고 안 하면 어떻게 되나요? (걱정 해결)
```

**좋은 H2 예시:**
```markdown
✅ ## 퇴직금 미지급 처벌 기준, 형사 대상인가요?
✅ ## 노동청 임금체불 신고 방법
✅ ## 청약 가점제 84점 만점 계산법
❌ ## 뭔가요?
❌ ## 신청
```

### H3 판단 기준 (Claude 스스로 판단!)

**주제마다 H3 개수가 다릅니다 (0개~4개). 고정 공식 없음!**

#### 1. 세분화 가능 → H3 2-4개 사용
**판단 기준:** H2 주제가 2개 이상 하위 개념으로 자연스럽게 나뉘는가?

**예시:**
- "신청 방법" → **온라인 신청 / 오프라인 신청 / 구비 서류** (3개)
- "처벌 기준" → **형사처벌 내용 / 추가 불이익 / 실제 사례** (3개)
- "계산 방법" → **계산 공식 / 예시 1 / 예시 2 / 주의사항** (4개)

#### 2. 세분화 어색 → H3 없이 바로 본문
**판단 기준:** 4-6문장으로 충분히 설명 가능한가?

**예시:**
- "~이란" (정의 설명) → H3 없이 본문 4-6문장
- "개념" (짧은 설명) → H3 없이 본문 4-6문장

#### 3. ⚠️ 억지로 만들지 말 것!
```
❌ "개념"을 "개념1", "개념2"로 억지 쪼개기
❌ "정의"를 "정의란", "정의 개요"로 중복
✅ 자연스러운 세분화만 사용
```

### H3 소제목 작성 규칙
- **구체적 단어 사용:** "온라인", "실제", "필요한"
- **괄호로 구체화:** "형사처벌 내용 (3년 징역 또는 3천만원 벌금)"
- **검색 쿼리 형태:** 실제 검색할 만한 표현

### 본문 작성 (H2/H3 공통)
- **H3 섹션당:** 4-6문장
- **구어체 필수:** ~이에요, ~해요, ~하죠
- **위기브 철학 유지:** 이해 쉽게, 궁금증 해결

**💡 완성 예시 참고:** [wegive-h2h3-example.md](./wegive-h2h3-example.md)

## 본문 작성 규칙

### 서론 (첫 문단)
- **독자 상황 공감** + **왜 중요한지**
- 160자 이내 권장
- 구어체 (~이에요, ~하죠)

### H2/H3 섹션
- **각 섹션 4문장 이상** (짧은 설명 + 테이블만 금지)
- **텍스트가 주인공** (테이블은 필요시만)
- **용어 풀이:** 전문용어 → 바로 쉽게 설명
- **내부링크:** 3개 이상 자연스럽게 삽입

**테이블 사용 기준:**
- ✅ 신청 절차 (단계별)
- ✅ A vs B 비교
- ✅ **은행/카드/상품별 비교** (CTR 최적화!)
- ✅ **지역별/면적별/기간별 조건 비교**
- ❌ 개념 설명 (텍스트로)
- ❌ 단순 나열 (불릿 포인트)

### 🔥 테이블 + 텍스트 조합 (필수 패턴!)

**⚠️ 테이블만 달랑 있으면 안 됨! 앞뒤 텍스트 필수!**

**패턴 구조:**
```markdown
[도입 텍스트] → 테이블 → [요약/팁 텍스트]
```

**실제 예시 (주택청약 1순위 예치금):**

```markdown
청약 신청하고자 하는 지역을 확인한 후, 가입 기간에서 1순위 조건을 충족하셨다면,
주택 면적에 따른 1순위 청약 예치금을 확인해 주세요.

| 면적 구분 | 서울/부산 | 기타 광역시 | 기타 시/군 |
|----------|----------|------------|-----------|
| 85㎡ 이하 | 300만 원 | 250만 원 | 200만 원 |
| 102㎡ 이하 | 600만 원 | 400만 원 | 300만 원 |
| 135㎡ 이하 | 1,000만 원 | 700만 원 | 400만 원 |
| 모든 면적 | 1,500만 원 | 1,000만 원 | 500만 원 |

지역별로 1순위 조건 예치금이 달라요. **청약 예치금을 신경 쓰기 귀찮으신 분들은
청약 통장에 1,500만 원 이상 넣어두시면 모든 면적에 신청할 수 있어요.**
```

**핵심 규칙:**
- **테이블 전:** 무엇을 비교하는지 설명 (1-2문장)
- **테이블 후:** 요약 + 꿀팁 (귀찮은 사람을 위한 팁!)
- **절대 금지:** 테이블만 덜렁 두기
