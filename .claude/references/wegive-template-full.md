#### ✅ 필수: 자연스러운 문장
```
"퇴직금 평균임금 산정 및 근속연수 계산 방법"
```
- 조사 "및" 사용
- 종결어 "방법" 사용
- 읽었을 때 문장처럼 들림
- **검증 통과!**

#### 검증 방법: 소리 내서 읽기 테스트
1. 타이틀을 소리 내서 읽어본다
2. 어색하면 → 조사(및/와/과) 추가
3. 종결이 이상하면 → ~방법, ~계산, ~산정 등 추가

## 퇴직금 미지급 처벌 기준, 형사 대상인가요?

퇴직금을 안 주면 사업주는 형사처벌을 받아요. [근로기준법 제109조](https://www.law.go.kr/법령/근로기준법)에서 명확하게 규정하고 있어요.

### 형사처벌 내용 (3년 징역 또는 3천만원 벌금)

퇴직일로부터 14일이 지나도 퇴직금을 안 주면 사업주는 3년 이하 징역 또는 3천만원 이하 벌금에 처해져요. 실제로 검찰에 송치되면 대부분 약식명령으로 벌금형을 받아요.

형사처벌은 민사소송과 별개예요. 벌금을 내더라도 퇴직금과 지연이자는 따로 지급해야 해요.

### 추가 불이익 (명단 공개, 입찰 제외)

형사처벌 외에도 여러 불이익이 있어요. 고용노동부는 매년 임금체불 사업주 명단을 공개해요. 사업장명, 대표자 성명, 체불액이 모두 공개돼요.

공공기관 입찰에서도 제외돼요. 체불액이 1억 원 이상이거나 2회 이상 반복되면 3년간 입찰 참가가 불가능해요.

### 실제 처벌 사례 (2025년 통계)

2025년 고용노동부 자료를 보면, 임금체불 형사입건이 연간 8,500건 이상이에요. 평균 벌금액은 350만원 정도예요.

징역형을 받은 사례도 있어요. 2024년 서울중앙지법에서 퇴직금 2억 원을 2년간 안 준 사업주에게 징역 1년을 선고했어요.

## 노동청 임금체불 신고 방법

퇴직금을 못 받았다면 관할 지방고용노동청에 임금체불 신고를 하면 돼요. 온라인이 가장 빠르고 간편해요.

### 온라인 신고 절차 (민원마당 10분 완료)

[고용노동부 민원마당](https://minwon.moel.go.kr)에 접속해서 임금체불 진정서를 작성해요. 제출하면 2주 내로 담당 근로감독관이 배정돼요.

### 필요 서류 및 증빙 자료

필수 서류는 진정서 하나예요. 근로계약서, 임금명세서, 퇴직증명서가 있으면 더 빨리 처리돼요. 증빙 자료가 없어도 국민연금 가입 이력으로 확인 가능해요.

### 신고 후 조사 진행 과정

근로감독관이 사업주에게 출석 요구서를 보내요. 조사 결과 체불이 확인되면 14일 내 지급 명령을 내려요. 불응하면 검찰 송치돼요.

## 퇴직금 지연이자 20% 계산법

퇴직일로부터 14일이 지나면 지연이자가 자동으로 발생해요. 연 20%예요.

### 계산 공식 및 적용 기준

공식: **퇴직금 × 20% × (지연일수 ÷ 365)**
예시: 1,000만원 × 0.20 × (30 ÷ 365) = 164,384원

### 실제 계산 예시 (3개월/6개월/1년)

- **3개월 (90일)**: 493,151원 추가
- **6개월 (180일)**: 986,301원 추가
- **1년 (365일)**: 200만원 추가

### 합의 시 주의사항

"지연이자 빼고 줄게" 제안은 거절하세요. 합의서에 지연이자 명시 필수예요.

### H3 판단 기준 (Claude 스스로 판단!)

**주제마다 H3 개수가 다릅니다 (0개~4개). 고정 공식 없음!**

#### 1. 세분화 가능 → H3 2-4개 사용
**판단 기준:** H2 주제가 2개 이상 하위 개념으로 자연스럽게 나뉘는가?

**예시:**
- "신청 방법" → **온라인 신청 / 오프라인 신청 / 구비 서류** (3개)
- "처벌 기준" → **형사처벌 내용 / 추가 불이익 / 실제 사례** (3개)
- "계산 방법" → **계산 공식 / 예시 1 / 예시 2 / 주의사항** (4개)

#### 2. 세분화 어색 → H3 없이 바로 본문
**판단 기준:** 4-6문장으로 충분히 설명 가능한가?

**예시:**
- "~이란" (정의 설명) → H3 없이 본문 4-6문장
- "개념" (짧은 설명) → H3 없이 본문 4-6문장

#### 3. ⚠️ 억지로 만들지 말 것!
```
❌ "개념"을 "개념1", "개념2"로 억지 쪼개기
❌ "정의"를 "정의란", "정의 개요"로 중복
✅ 자연스러운 세분화만 사용
```

### H3 소제목 작성 규칙
- **구체적 단어 사용:** "온라인", "실제", "필요한"
- **괄호로 구체화:** "형사처벌 내용 (3년 징역 또는 3천만원 벌금)"
- **검색 쿼리 형태:** 실제 검색할 만한 표현

### 본문 작성 (H2/H3 공통)
- **H3 섹션당:** 4-6문장
- **구어체 필수:** ~이에요, ~해요, ~하죠
- **위기브 철학 유지:** 이해 쉽게, 궁금증 해결

**💡 완성 예시 참고:** [wegive-h2h3-example.md](./wegive-h2h3-example.md)

## 본문 작성 규칙

### 서론 (첫 문단)
- **독자 상황 공감** + **왜 중요한지**
- 160자 이내 권장
- 구어체 (~이에요, ~하죠)

### H2/H3 섹션
- **각 섹션 4문장 이상** (짧은 설명 + 테이블만 금지)
- **텍스트가 주인공** (테이블은 필요시만)
- **용어 풀이:** 전문용어 → 바로 쉽게 설명
- **내부링크:** 3개 이상 자연스럽게 삽입

**테이블 사용 기준:**
- ✅ 신청 절차 (단계별)
- ✅ A vs B 비교
- ✅ **은행/카드/상품별 비교** (CTR 최적화!)
- ✅ **지역별/면적별/기간별 조건 비교**
- ❌ 개념 설명 (텍스트로)
- ❌ 단순 나열 (불릿 포인트)

### 🔥 테이블 + 텍스트 조합 (필수 패턴!)

**⚠️ 테이블만 달랑 있으면 안 됨! 앞뒤 텍스트 필수!**

**패턴 구조:**
```markdown
[도입 텍스트] → 테이블 → [요약/팁 텍스트]
```

**실제 예시 (주택청약 1순위 예치금):**

```markdown
청약 신청하고자 하는 지역을 확인한 후, 가입 기간에서 1순위 조건을 충족하셨다면,
주택 면적에 따른 1순위 청약 예치금을 확인해 주세요.

| 면적 구분 | 서울/부산 | 기타 광역시 | 기타 시/군 |
|----------|----------|------------|-----------|
| 85㎡ 이하 | 300만 원 | 250만 원 | 200만 원 |
| 102㎡ 이하 | 600만 원 | 400만 원 | 300만 원 |
| 135㎡ 이하 | 1,000만 원 | 700만 원 | 400만 원 |
| 모든 면적 | 1,500만 원 | 1,000만 원 | 500만 원 |

지역별로 1순위 조건 예치금이 달라요. **청약 예치금을 신경 쓰기 귀찮으신 분들은
청약 통장에 1,500만 원 이상 넣어두시면 모든 면적에 신청할 수 있어요.**
```

**핵심 규칙:**
- **테이블 전:** 무엇을 비교하는지 설명 (1-2문장)
- **테이블 후:** 요약 + 꿀팁 (귀찮은 사람을 위한 팁!)
- **절대 금지:** 테이블만 덜렁 두기
