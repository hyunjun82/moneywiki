## 본문 구조

### 서론 (160자 이내)

```markdown
[독자 상황 공감 1문장]. [왜 중요한지 1문장]. [이 글에서 해결할 것 1문장].
```

**예시**:
> 전세 2년 살았는데 집주인이 나가라고 해요. 억울하죠? 계약갱신청구권으로 2년 더 살 수 있어요. 조건과 방법 알려드릴게요.

### H2 소제목 (Keywords 4개 = H2 4개)

**필수 규칙**: 모든 H2에 베이스 키워드 포함!

```markdown
## [베이스키워드], 정확히 뭐예요?
## [베이스 + 확장어1] 조건은요?
## [베이스 + 확장어2] 방법 알려주세요
## [베이스 + 확장어3] 주의할 점은요?
```

**H2 질문 유형 8가지**:
| 유형 | 패턴 | 예시 |
|------|------|------|
| 정의 | ~, 뭐예요? | 가압류, 정확히 뭐예요? |
| 조건 | ~ 조건은요? | 가압류 신청 조건은요? |
| 방법 | ~ 방법 알려주세요 | 가압류 신청 방법 알려주세요 |
| 비용 | ~ 비용 얼마예요? | 가압류 신청 비용 얼마예요? |
| 기간 | ~ 기간 얼마나 걸려요? | 가압류 해제 기간 얼마나 걸려요? |
| 비교 | ~ vs ~ 뭐가 나아요? | 가압류 vs 가처분 뭐가 나아요? |
| 주의 | ~ 주의할 점은요? | 가압류 신청 주의할 점은요? |
| 꿀팁 | ~ 꿀팁 있나요? | 가압류 비용 절약 꿀팁 있나요? |

---

### 본문 작성 규칙

1. **각 섹션 4문장 이상** (텍스트가 주인공)
2. **구어체 필수**: ~이에요, ~해요, ~하죠, ~거든요
3. **테이블 2개 이하** (비교/절차만)
4. **내부링크 2~3개**: `[키워드](/w/슬러그)`
5. **외부링크 1개 버튼**: 신청/조회/다운로드용

**외부 버튼 형식**:
```markdown
<div class="cta-button">
  <a href="https://정부사이트URL" target="_blank" rel="noopener">
    지금 바로 신청하기 →
  </a>
</div>
```
