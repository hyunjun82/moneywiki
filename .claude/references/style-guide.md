# 머니위키 Style Guide — 문체/톤 (Layer 3)

> 모든 글에 공통. "무엇을 쓰느냐"가 아니라 "어떻게 쓰느냐".

---

## 구어체 규칙

```
필수: ~이에요, ~해요, ~돼요, ~있어요, ~거예요, ~이죠
금지: ~습니다, ~합니다, ~됩니다 (관공서체)
```

쉽게 말하면 "카카오톡으로 설명해주는 느낌". 20세든 80세든 읽히는 문장.

---

## 서론 5줄 구조

| 줄 | 역할 | 예시 |
|----|------|------|
| 1줄 (이탤릭) | 독자 실제 검색 질문 | *"퇴직금 14일 넘기면 이자가 붙는다는데?"* |
| 2~3줄 | 핵심 사실 + 숫자 | "연 20% 지연이자, 지급기한은 14일이에요." |
| 4줄 | 왜 중요한지 | "모르면 수백만 원을 놓칠 수 있어요." |
| 5줄 | 동행 톤 마무리 | "정부 공식 자료로 정리했어요." |

**금지**: "확인해 보세요", "알아보겠습니다", 명령형 CTA

### 서론 실제 예시

```markdown
*"퇴직연금 수익률이 2%대라는데, 국채로 바꾸면 뭐가 달라지는 거야?"*

올해 9월, 퇴직연금 계좌 안에서 국채를 직접 살 수 있는 길이 열려요. 재정경제부는 2월 12일 '연금형 개인투자용 국채 추진협의체' 제1차 회의를 열고 제도 준비 상황을 점검했어요. 일반 국민이 퇴직연금으로 개인투자용 국채에 접근하는 건 이번이 처음이에요.

가산금리 확대에 세제혜택까지 겹치면서 기존 원리금보장형 상품과 구조적 차이가 확 벌어졌어요.
정부 공식 발표 자료만 가지고 정리했어요.
```

## Anti-AI 패턴

| 금지 패턴 | 이유 | 대안 |
|----------|------|------|
| "예시 1, 예시 2, 예시 3" | 순번 H3 = AI 티 | 인물/상황/질문 중심 H3 |
| 같은 전환 표현 2회 | 반복 = 기계적 | 아래 풀에서 돌려쓰기 |
| "확인하세요" | 명령형 CTA | "정리했어요" / "알려드릴게요" |
| "총정리", "완벽정리" | 스팸 느낌 | 사용하지 않음 |
| "그렇다면 X일까요?" 2회+ | 전환 반복 | 글 전체 최대 1회 |

---

## 전환 표현 풀 (같은 글에서 반복 금지)

### 도입/전환
- "그렇다면 ~싶겠지만"
- "여기서 중요한 건"
- "한 가지 더 알아두실 게 있어요"
- "그러니까 정리하면"
- "구체적으로 보면 이래요"

### 강조/부연
- "쉽게 말하면"
- "~라는 뜻이에요"
- "~하는 셈이에요"
- "핵심은 이거예요"
- "먼저 ~그 다음에"

### 주의/경고
- "다만 주의할 점이 있어요"
- "놓치기 쉬운 부분인데"
- "많이들 헷갈리시는 게"
- "여기서 함정이 있어요"
- "이 부분은 꼭 기억하세요"

### 예시 전환
- "실제로 보면"
- "구체적인 숫자로 보면"
- "OO씨 사례를 보면"
- "상황을 바꿔서 보면"
- "같은 조건인데 결과가 달라요"

### 독자 질문 전환 (섹션 넘길 때)
- "그런데 왜 지금 이게 주목받는 걸까요?"
- "그러면 실제로 내 돈을 넣으면 얼마나 차이 나는지 궁금하죠?"
- "그렇다면 지금 신청하는 게 나을까요?"
- "그럼 나는 어디에 해당하는 걸까요?"
- "다음으로 궁금한 건 아마 이거일 거예요"

## mark 태그 (3~4곳만)

독자가 스크롤하면서 시선 멈추는 핵심 숫자/사실에만.

```markdown
실업급여 1일 지급액은 <mark>**퇴직 전 평균임금의 60%**</mark>예요.
총급여 5,500만 원 이하면 <mark>**16.5%**</mark>예요.
```

금지: 문단마다 mark, 문장 전체 mark, 5개 이상

## bridge-card 3가지 hook (같은 글 내 반복 금지)

- **놀라움**: "~아셨나요?" / "~라는 거 아시나요?"
- **공감**: "~부담되시나요?" / "~걱정이시죠?"
- **궁금증**: "~될 수 있을까요?" / "~얼마나 차이 날까요?"

글 1개에 bridge-card 1~2개만. bridge-btn 금지어: "자세히 보기", "전체 가이드", "바로가기", "확인하세요"
