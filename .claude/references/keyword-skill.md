# 머니위키 키워드 타이틀 추출 시스템

## 🎯 핵심 규칙

```
타이틀 → 키워드 4개 → 소제목 4개 (완벽 일치!)

타이틀 = 전체 주제
키워드 = 타이틀을 4개로 분해
소제목 = 키워드 그대로 사용

절대 규칙:
1. 타이틀 숫자 1개만!
2. 콜론 뒤는 명사형! (구어체 금지)
3. 키워드 4개는 타이틀 분해!
4. 키워드 = 본문 소제목!

예시:
title: "퇴직금 세금 공제: 퇴직소득세 원천징수 기준"
keywords:
  - 퇴직금 세금 공제        ← 타이틀 앞
  - 퇴직소득세 원천징수     ← 타이틀 뒤
  - 퇴직금 세금 계산        ← 세부 내용
  - 퇴직소득세 세율         ← 세부 내용
본문 소제목:
  ## 퇴직금 세금 공제란?
  ## 퇴직소득세 원천징수 방법
  ## 퇴직금 세금 계산 방법
  ## 퇴직소득세 세율

⚠️ 불필요한 단어 금지:
키워드 끝에 "정리", "확인", "비교표", "서류" 불필요!
✅ "퇴직소득세 세율" (간결!)
❌ "퇴직소득세 세율 비교표" (불필요!)
❌ "공제액 계산 방법 정리" (불필요!)
```

## 📋 타이틀 작성 공식

```
[3-4단어 핵심 키워드]: [명사형 격식 표현]

⚠️ 절대 규칙: 
1. 숫자는 1개만!
2. 콜론 뒤는 명사형 (구어체 금지)

✅ OK:
"부동산 중개보수 부담 주체: 임대인과 임차인 부담 기준"
"묵시적 갱신 후 법률 관계: 계약 기간 및 임차인 해지 권리"
"상가임대차 갱신 계약의 중도 해지: 가능 여부 및 위약금"

❌ NO:
"실업급여 지급 기간: 연령별 최대 몇 개월" (구어체!)
"4대보험 공제액: 월급에서 얼마나 떼는지" (구어체!)

패턴:
✅ "~별 차이", "~및 비교", "가능 여부 및 ~", "~기준"
❌ "몇 개월", "얼마나", "~는지", "~하나요"

판단 기준:
1. 숫자 1개만
2. 명사형 (격식 있게)
3. 32자 이내
```

## 📐 Description 작성 규칙

**패턴: [문제 제시 ~라는 거 아시나요?] [해결책 ~알려드려요]**

```
길이: 80-120자

✅ 좋은 예:
"내가 가입한 보험 기억 안 나서 숨은 보험금 날리고 있다는 거 아시나요? 본인인증 한 번으로 가입 내역 전체 조회하는 방법을 알려드려요"

주의사항:
- 구체적 금액은 조심 (잘못된 정보 위험)
- 과격한 단어 사용 금지 (폭탄 등)

금지 표현:
❌ "알아봅니다", "살펴봅니다", "확인하세요", "총정리", "꿀팁"
✅ "~라는 거 아시나요?", "알려드려요", "정리해드려요"
```

## 🎯 Keywords 작성 규칙

**정확히 4개 (타이틀 분해!)**

```yaml
절대 규칙:
1. 타이틀을 4개로 분해
2. 키워드 = 본문 소제목
3. 불필요한 단어 제거 ("정리", "확인", "비교표", "서류")
4. 간결하게!

✅ 좋은 예:
title: "퇴직금 세금 공제: 퇴직소득세 원천징수 기준"
keywords:
  - 퇴직금 세금 공제        ← 타이틀 앞부분
  - 퇴직소득세 원천징수     ← 타이틀 뒷부분
  - 퇴직금 세금 계산        ← 세부 내용
  - 퇴직소득세 세율         ← 세부 내용

title: "실업급여 지급 기간: 연령 및 가입기간별 차이"
keywords:
  - 실업급여 지급 기간     ← 타이틀 핵심
  - 연령별 실업급여        ← 타이틀 세부
  - 가입기간별 실업급여    ← 타이틀 세부
  - 실업급여 기간 차이     ← 타이틀 마무리

❌ 나쁜 예:
keywords:
  - 퇴직소득세 세율 비교표  ← "비교표" 불필요!
  - 대인보험 가입 기준 서류 ← "서류" 불필요!
  - 공제액 계산 방법 정리   ← "정리" 불필요!
  - 국민연금 200만원
  - 국민연금 200만원 상위 몇 프로  ← 거의 중복!
```

## 🔍 1차 검토 (생성 후 자가 점검)

```
타이틀 + 키워드 + H2 소제목 일관성 체크:
□ 키워드 4개가 H2 소제목 4개와 1:1 매칭?
□ 타이틀 핵심어가 키워드에 반영?
□ H2 소제목이 PAA 질문 형태? (~뭔가요? ~어떻게 하나요?)

자연스러움 체크:
□ 타이틀 소리 내서 읽으면 자연스러움?
□ H2 소제목이 실제 검색 질문처럼 들림?
□ 어색한 표현 없음?

1차 검토 통과 → 2차 검토(keyword-extraction-workflow.md)로 전달
```
