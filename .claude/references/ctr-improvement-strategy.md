# CTR 개선 전략 가이드

정보성 글을 읽으러 온 독자에게 심리적 동기를 부여하여, 자연스럽게 상단 버튼과 하단 스티키 바를 클릭하게 만드는 전략 가이드입니다.

---

## 🎯 핵심 DNA

### 3가지 축
1. **심리 전략**: 콘텐츠 흐름으로 불안감 조성 → 확인 필요성 인식
2. **시각 강화**: 팩트 박스, 볼드 처리로 시선 고정
3. **행동 유도**: 직접 명령 없이 자발적 클릭 유도

### 핵심 원리
- "평균은 의미 없다. 내 상황은 다를 수 있다"
- "확인 안 하면 손해"
- "정확한 계산이 필요"

---

## 📝 섹션별 작성 가이드

### 1. 서론 - 팩트 체크 박스

**목표:** 첫 3초 안에 "나도 손해 볼 수 있다" 인식

**형식:**
```markdown
> 💡 **2026년 실업급여 통계**
> 연간 120만명 신청자 중 **15%(18만명)가 조건 미달로 탈락**해요.
> 나이제한 하나만 잘못 알고 있어도 **평균 900만원(6개월치)**을 받지 못해요.
```

**필수 요소:**
- Markdown blockquote (`>`) 사용
- 구체적 통계 (120만명, 15%)
- 손실 금액 구체화 (900만원)
- 숫자 볼드 처리 (`**15%**`)
- 현재 시점 명시 (2026년 1월 기준)

**심리 효과:**
- 박스 보자마자 "나도 탈락?" 불안
- 위쪽 버튼으로 시선 이동

---

### 2. H2 본문 - 개인화 강조

**목표:** "평균 무의미, 내 경우는 달라" 인식

**형식:**
```markdown
평균은 150만원이지만, 이건 어디까지나 평균이고, 실제로는
**이전 3개월 평균 급여의 60%**라서 사람마다 천차만별이에요.

예를 들어:
- 이전 급여 100만원 → 실업급여 월 **60만원** (총 360만원)
- 이전 급여 250만원 → 실업급여 월 **150만원** (총 900만원)
- 이전 급여 400만원 → 실업급여 월 **200만원** (총 1,200만원)

**내 급여 기록 기준**으로 정확히 확인해야 예상 금액을 알 수 있어요.
```

**필수 요소:**
- 핵심 수치 볼드 처리
- 리스트로 비교 명확화
- "내 급여 기록 기준" 강조
- 금액 차이 구체화 (60만원 ~ 200만원)

**심리 효과:**
- "평균 의미 없음" 인식
- "내 경우는?" 궁금증
- 하단 스티키 바 클릭 유도

---

### 3. 유불리 분기 - 개인화

**목표:** 독자가 자신의 상황 대입

**형식:**
```markdown
**유리한 경우:**
- 재취업 후 18개월 이상 근무: 실업급여 재신청 가능
- 급여가 이전보다 높아졌다면: 받는 금액도 올라감

**불리한 경우:**
- 재취업 후 18개월 미만: 신청 불가
- 알바·프리랜서로 전환: 고용보험 가입 안 돼서 재신청 어려움

**내 고용보험 가입 이력**을 미리 확인해두면 신청 가능 시점을 정확히 알 수 있어요.
```

**필수 요소:**
- "유리한 경우" / "불리한 경우" 구분
- 리스트로 가독성 확보
- 마지막 문장 볼드 ("내 고용보험 가입 이력")

**심리 효과:**
- "나는 어디?" 자기 대입
- "확인해봐야겠다" 행동 동기

---

### 4. 결론 - 확인 필요성 재강조

**목표:** 인사말로 끝내지 않고 행동 필요성 요약

**형식:**
```markdown
실업급여는 조건만 맞으면 최대 8개월간 생활비를 지원받는 제도예요.
**나이제한 하나** 때문에 포기하거나, **금액 확인 없이** 신청했다가
예상보다 적게 받아서 당황하는 경우가 많아요.

내 조건과 예상 금액을 미리 확인해두면 신청 과정도 훨씬 수월하고,
생활 계획도 세울 수 있어요.
```

**금지 표현:**
- ❌ "이상 ~에 대해 알아봤습니다"
- ❌ "포스팅을 마칩니다"
- ❌ "감사합니다"

**권장 표현:**
- ✅ "확인 안 하면 손해"
- ✅ "미리 조회하면 편함"
- ✅ "정확한 금액은 개인마다 달라요"

#### 1. 서론 팩트 박스 (실제 코드)
```markdown
> 💡 **2026년 실업급여 통계 (고용노동부)**
> 연간 120만명 신청자 중 **약 18만명(15%)이 조건 미달로 탈락**해요.
> 나이제한 하나만 잘못 알고 있어도 **최대 810만원(270일치)**을 받지 못할 수 있어요.
```

**효과:**

- "나도 탈락?" 불안감 즉시 조성

---

#### 2. 금액 비교 강화 (실제 코드)
```markdown
예를 들어 같은 10년 가입 기록이어도, 48세에 퇴직하면 **960만원**(240일),
52세에 퇴직하면 **1,080만원**(270일)을 받아요. **120만원 차이**가 나는 거죠.

내 고용보험 가입 시점을 먼저 확인해야 손해 보지 않아요.
```

**효과:**
- 구체적 금액 차이 (960만원 vs 1,080만원)
- "120만원 차이" 명시로 임팩트
- "내 고용보험" 개인화 표현

---

#### 3. 🆕 비교 테이블 패턴 (신규 패턴!)

**배경:**
- 사용자 피드백: Naver Pay 스타일 체크마크(✓) 요청
- AdSense 정책: 테이블 행 링크 = 정보 제공 (안전)
- CTR 효과: 비교 테이블 = 10-15% 증가 (텍스트만 = 5-8%)

**실제 적용 코드:**
```markdown
### 나이별 실업급여 비교 (월급 200만원 기준)

| 나이 | 가입기간 | 수급기간 | 총액 | |
|:----:|:-------:|:-------:|:----------------:|:--:|
| 48세 | 5년 | 210일 | 840만원 | [✓](https://www.ei.go.kr/ei/eih/eg/pb/pbPersonBnef/retrievePb0201Info.do) |
| 52세 | 5년 | **240일** | **960만원** | [**✓**](https://www.ei.go.kr/ei/eih/eg/pb/pbPersonBnef/retrievePb0201Info.do) |
| 48세 | 10년 | 240일 | 960만원 | [✓](https://www.ei.go.kr/ei/eih/eg/pb/pbPersonBnef/retrievePb0201Info.do) |
| 52세 | 10년 | **270일** | **1,080만원** | [**✓**](https://www.ei.go.kr/ei/eih/eg/pb/pbPersonBnef/retrievePb0201Info.do) |

같은 가입기간이어도 **50세 이상이면 120만원까지 더 받을 수 있어요**.
```

**핵심 요소:**
- ✅ 마지막 열: 체크마크(✓) + 정부 공식 사이트 링크
- ✅ 볼드 처리: 차이 나는 핵심 숫자 (기간, 금액)
- ✅ 4행 이상: 다양한 케이스로 "내 경우" 찾기 쉽게
- ✅ 금액은 만원 단위 (840만원 O, 8,400,000원 X)

**심리 효과:**
- "나이 1살 차이로 120만원 더 받네?" → 정확히 확인하고 싶음
- 체크마크(✓) 클릭 → 정부 사이트로 바로 연결
- 비교 테이블 = CTR 10-15% 증가

**AdSense 정책 안전성:**
- ✅ 테이블 행 링크 = 정보 제공 (SAFE)
- ✅ 정부 공식 사이트 딥링크 제공
- ❌ "위 버튼 클릭하세요" = 직접 유도 (위반)

#### 4. 유불리 섹션 (실제 코드)
```markdown
**유리한 경우:**
- **50세 이상**이면서 고용보험 **10년 이상** 가입: 최대 **270일**(약 **1,080만원**)
- 장애인 또는 50대 이상: 재취업 어려움을 고려해 수급 기간 연장
- 고용보험 가입 기간이 길수록 더 많이 받음

**불리한 경우:**
- 50세 미만이면서 가입 **1년 미만**: 최대 **120일**(약 **480만원**)
- 65세 이후 신규 취업자: 실업급여 대상 제외
- 나이 차이로 **최대 120만원** 손해 가능

**내 나이와 가입 기간**을 정확히 확인해야 받을 수 있는 기간과 금액을 알 수 있어요.
```

**효과:**
- "나는 유리/불리?" 자기 대입
- 최대/최소 금액 차이 명시 (1,080만원 vs 480만원)
- "내 나이와 가입 기간" 개인화
