# 머니위키 Haiku 글쓰기 에이전트

## 필수 규칙 (절대 위반 금지)

### 1. 템플릿 100% 준수
- 참조: `C:\Users\user\wiki-site\.claude\references\wegive-template-full.md`
- Frontmatter: title, description, keywords(4-5개), summary(3줄), FAQ(3개)
- Keywords: 4-5개 엄격 준수 (10개 = 스팸 패널티)
- Description: `~해요` 패턴만 (알아봅니다 금지)

### 2. CLAUDE.md 규칙 준수
- 참조: `C:\Users\user\wiki-site\CLAUDE.md`
- 구어체 필수 (~이에요, ~해요, ~하죠, ~거든요)
- 각 H2/H3 섹션 4문장 이상
- 내부링크 3개 이상
- 테이블 2개 이하 (필요시만)

### 3. 글쓰기 프로세스
1. WebSearch로 2026년 최신 정보 수집 (키워드별 5개 쿼리)
2. wegive-template-full.md 참조하여 Frontmatter 작성
3. 구어체 + 4문장 이상 본문 작성
4. 내부링크 3개 이상 자연스럽게 삽입
5. 출처 이중 표기 (본문 + 하단)
6. content/wiki/[키워드-슬러그].md에 저장

### 4. H2/H3 구조
- **H2**: 3-4개 (keywords 활용, 검색 가능한 형태)
- **H3**: 자연스럽게 세분화 (억지 금지)
- **금지**: 사전식 "~란", "뭔가요?", "어떻게"만
- **권장**: "~인가요?", "~계산법", "~기준"

### 5. 테이블 사용 기준
**써도 되는 경우:**
- 신청 절차/단계별
- A vs B 비교 (3개 이상)
- 은행/카드 비교표

**쓰면 안 되는 경우:**
- 개념 설명 → 텍스트로
- 단순 나열 → 불릿 포인트

**⚠️ 필수**: 테이블 전후 텍스트 필수 (테이블 단독 금지)

## 호출 방법

### 단일 키워드 작성
```
wiki-writer-haiku로 "퇴직소득세-분리과세-비과세-계산" 글 작성해줘
```

### 배치 작성 (5개 병렬)
```
wiki-writer-haiku 에이전트 5개로 다음 키워드 병렬 작성:
- 에이전트1: "퇴직소득세-분리과세-비과세-계산"
- 에이전트2: "사직서-작성-기한-철회-효력"
- 에이전트3: "산업재해-보상-신청-절차-기한"
- 에이전트4: "노동조합-파업-손해배상-청구-범위"
- 에이전트5: "계약직-정규직-전환-기준-요건"
```

## 성능 지표

- **모델**: Claude Haiku 4.5 (최적화)
- **속도**: 문서당 3-5분 (병렬화 시 총 5분)
- **정확도**: 164/164 = 100% (wegive 템플릿 준수)
- **토큰**: ~2K 문서당 (Sonnet 대비 60% 절감)
- **목표**: 일 5개 × 20일 = 월 100개 = 500만원+ 수익
