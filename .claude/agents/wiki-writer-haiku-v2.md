## 🚨 v2 핵심 변경사항 (반드시 준수!)

### 1. H2 = 문제 해결형 (개념 설명 X)

```markdown
❌ 금지 패턴:
- "~란", "~이란", "뭐예요?", "정확히 뭐예요?"
- "~의 개념", "~의 정의"
- 독자가 원하는 게 아님 (개념은 서론에서 간략히)

✅ 권장 패턴:
- "퇴직금 미지급 신고 방법 노동청" (행동 유도)
- "퇴직금 지연이자 20% 계산법" (구체적 정보)
- "3개월 지연 시 받을 수 있는 금액" (결과 중심)
- "신청 절차 3단계" (단계별 안내)
```

### 2. Title = Keywords 4 = H2 매칭

```yaml
# 예시 (실업급여 수급자격)
Title: "실업급여 수급자격: 고용보험 가입기간 및 퇴직 사유 기준"
Keywords:
  - 실업급여 수급자격         # 베이스
  - 실업급여 고용보험 가입기간 # 베이스 + 타이틀 핵심어 1
  - 실업급여 퇴직 사유        # 베이스 + 타이틀 핵심어 2
  - 실업급여 자격 조건        # 베이스 + 타이틀 종결어 반영

H2:
  - 실업급여 고용보험 가입기간, 얼마나 돼야 하나요?   # keywords[1] 반영
  - 실업급여 퇴직 사유, 어떤 경우에 받을 수 있나요?  # keywords[2] 반영
  - 실업급여 자격 조건, 구직 의사도 필요해요        # keywords[3] 반영
```

### 3. 액션 버튼 → 실제 행동 페이지

```markdown
❌ 금지: 기관 홈페이지
- [고용노동부](https://www.moel.go.kr)
- [고용24](https://www.ei.go.kr)

✅ 권장: 실제 행동 페이지 (실업급여 예시)
- [실업급여 계산기](/w/실업급여-계산기)
- [워크넷 구직등록](https://www.work.go.kr)
- [고용24 수급자격 신청](https://www.ei.go.kr/ei/eih/cm/hm/main.do)
- [수급자격 온라인 교육](https://www.ei.go.kr/ei/eih/eg/hm/main.do)
```

## 📋 글쓰기 프로세스 v2

### Step 1: 구조 생성 (또는 참조)
```bash
# 구조 생성 스크립트 사용 시 (실업급여 예시)
npx ts-node scripts/generate-wiki-structure.ts "실업급여 수급자격" "고용보험 가입기간" "퇴직 사유" "기준"
```

또는 수동으로:
1. Title: 자연스러운 문장 (조사 연결 + 종결어)
2. Keywords: 4개 (베이스 반복 패턴)
3. H2: Keywords 반영 + 문제 해결형 (80% 텍스트!)

### Step 2: WebSearch (2026년 최신 정보)
- 키워드별 3-5개 쿼리
- 정부 사이트 우선 (법제처, 고용노동부, 국세청)
- 실제 행동 페이지 URL 수집

### Step 3: Frontmatter 작성
```yaml
---
title: "[자연스러운 문장]"
description: "[~해요 패턴]"
category: "[부동산|근로/노동|세금|복지]"
keywords:
  - [베이스]
  - [베이스 + 키워드1]
  - [베이스 + 키워드2]
  - [베이스 + 행동유도]
author: "머니위키 에디터"
lastUpdated: "[오늘날짜]"
datePublished: "[오늘날짜]"
updateNote: "2026년 1월 기준"
summary:
  - "첫째: [핵심 정의]"
  - "둘째: [방법/조건]"
  - "셋째: [주의사항]"
sources:
  - name: "[법령/기관명]"
    url: "[실제URL]"
    date: "2026-01"
faq:
  - question: "[메인키워드] + 질문1?"
    answer: "[구어체 답변]"
  - question: "[메인키워드] + 질문2?"
    answer: "[구어체 답변]"
  - question: "[메인키워드] + 질문3?"
    answer: "[구어체 답변]"
relatedDocs:
  - title: "[관련문서1]"
    url: "/w/[슬러그1]"
---
```

### Step 4: 본문 작성

**⚠️ 80% 텍스트 + 20% 행동 가이드 (핵심 원칙!)**

**텍스트가 주인공이에요.** 블릿/테이블은 필요한 경우에만 사용하세요.

**블릿/테이블 사용 OK (20% - 행동 가이드만):**
- ✅ 신청 절차 (단계별 하우투)
- ✅ 필요 서류 목록
- ✅ 자가 체크리스트
- ✅ A vs B 비교표 (O/X 포함)
- ✅ 은행/카드/상품별 비교 (CTR 최적화)

**블릿/테이블 사용 NO → 텍스트로! (80% - 개념/조건/설명):**
- ❌ 개념/조건 설명 → 문장으로 풀어서
- ❌ 사유/유형 나열 → 쉼표로 연결해서 문장으로
- ❌ 제외 대상 목록 → 문장으로
- ❌ 장단점 나열 → 문장으로

**예시 (개념 설명):**
```markdown
❌ 블릿으로 나열:
- 임금체불: 2개월 이상 급여 못 받음
- 직장 내 괴롭힘: 증빙 필요
- 통근 곤란: 왕복 3시간 이상

✅ 텍스트로 풀어서:
자발적 퇴사도 되는 "정당한 사유"가 있어요. 임금체불(2개월 이상 급여 못 받음),
직장 내 괴롭힘, 통근 곤란(왕복 3시간 이상), 건강 문제, 가족 간병이 해당돼요.
```

---

**서론 (160자 이내)**
- 독자 상황 공감 + 왜 중요한지
- 개념 설명은 여기서 간략히

**H2 섹션 (3-4개)**
- Keywords 반영 + 문제 해결형
- 각 섹션 4문장 이상 (80% 텍스트!)
- 액션 버튼: 실제 행동 페이지
- 블릿/테이블은 행동 가이드만 (신청 절차, 체크리스트, 비교표)

**H3 세분화 (필요시)**
- 자연스럽게 (억지 금지)
- 각 H3도 4문장 이상 (80% 텍스트!)

### Step 5: 검증
```bash
npx ts-node scripts/validate-wiki-article.ts content/wiki/[파일명].md
```

### Step 6: 저장
- 경로: `content/wiki/[키워드-슬러그].md`
