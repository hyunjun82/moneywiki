## 🚨 v2 핵심 변경사항 (반드시 준수!)

### 1. H2 = 문제 해결형 (개념 설명 X)

```markdown
❌ 금지 패턴:
- "~란", "~이란", "뭐예요?", "정확히 뭐예요?"
- "~의 개념", "~의 정의"
- 독자가 원하는 게 아님 (개념은 서론에서 간략히)

✅ 권장 패턴:
- "퇴직금 미지급 신고 방법 노동청" (행동 유도)
- "퇴직금 지연이자 20% 계산법" (구체적 정보)
- "3개월 지연 시 받을 수 있는 금액" (결과 중심)
- "신청 절차 3단계" (단계별 안내)
```

### 2. Title = Keywords 4 = H2 매칭

```yaml
# 예시
Title: "퇴직금 미지급 신고 및 지연이자 받는법"
Keywords:
  - 퇴직금 미지급           # 베이스
  - 퇴직금 미지급 신고       # 베이스 + 신고
  - 퇴직금 지연이자         # 베이스 변형
  - 퇴직금 미지급 받는법     # 베이스 + 행동유도

H2:
  - 퇴직금 미지급 신고 방법 노동청   # keywords[1] 반영
  - 퇴직금 지연이자 20% 계산법      # keywords[2] 반영
```

### 3. 액션 버튼 → 실제 행동 페이지

```markdown
❌ 금지: 기관 홈페이지
- [고용노동부](https://www.moel.go.kr)
- [국세청](https://www.nts.go.kr)

✅ 권장: 실제 행동 페이지
- [민원마당 신고하기](https://minwon.moel.go.kr)
- [퇴직금 계산기](/calculators/severance)
- [신청서 양식 다운로드](https://www.moel.go.kr/info/lawinfo/form.do)
```

## 📋 글쓰기 프로세스 v2

### Step 1: 구조 생성 (또는 참조)
```bash
# 구조 생성 스크립트 사용 시
npx ts-node scripts/generate-wiki-structure.ts "퇴직금 미지급" "신고" "지연이자" "받는법"
```

또는 수동으로:
1. Title: 자연스러운 문장 (중간점 1-2개만, 강제 X)
2. Keywords: 4개 (베이스 반복 패턴)
3. H2: Keywords 반영 + 문제 해결형

### Step 2: WebSearch (2026년 최신 정보)
- 키워드별 3-5개 쿼리
- 정부 사이트 우선 (법제처, 고용노동부, 국세청)
- 실제 행동 페이지 URL 수집

### Step 3: Frontmatter 작성
```yaml
---
title: "[자연스러운 문장]"
description: "[~해요 패턴]"
category: "[부동산|근로/노동|세금|복지]"
keywords:
  - [베이스]
  - [베이스 + 키워드1]
  - [베이스 + 키워드2]
  - [베이스 + 행동유도]
author: "머니위키 에디터"
lastUpdated: "[오늘날짜]"
datePublished: "[오늘날짜]"
updateNote: "2026년 1월 기준"
summary:
  - "첫째: [핵심 정의]"
  - "둘째: [방법/조건]"
  - "셋째: [주의사항]"
sources:
  - name: "[법령/기관명]"
    url: "[실제URL]"
    date: "2026-01"
faq:
  - question: "[메인키워드] + 질문1?"
    answer: "[구어체 답변]"
  - question: "[메인키워드] + 질문2?"
    answer: "[구어체 답변]"
  - question: "[메인키워드] + 질문3?"
    answer: "[구어체 답변]"
relatedDocs:
  - title: "[관련문서1]"
    url: "/w/[슬러그1]"
---
```

### Step 4: 본문 작성

**서론 (160자 이내)**
- 독자 상황 공감 + 왜 중요한지
- 개념 설명은 여기서 간략히

**H2 섹션 (3-4개)**
- Keywords 반영 + 문제 해결형
- 각 섹션 4문장 이상
- 액션 버튼: 실제 행동 페이지

**H3 세분화 (필요시)**
- 자연스럽게 (억지 금지)
- 각 H3도 4문장 이상

### Step 5: 검증
```bash
npx ts-node scripts/validate-wiki-article.ts content/wiki/[파일명].md
```

### Step 6: 저장
- 경로: `content/wiki/[키워드-슬러그].md`
