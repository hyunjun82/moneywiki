# 슈퍼 롱테일 키워드 생성기 v1.1

## 입출력

```
입력: 시드 키워드 1개 (예: "법인세")
출력: 타이틀 + 키워드 4개 + H2 4개
확장: 중복 없이 10~100개
```

---

## 핵심 규칙

```
타이틀 → 키워드 4개 추출 → H2 = 키워드 + 질문 (완벽 일치)
```

**위반 시 재생성**

---

## 1단계: 타이틀 생성

### 패턴 라이브러리 (10개)

| # | 패턴 | 예시 |
|---|------|------|
| 1 | {K1}과 {K2} | 법인세 신고 기한과 납부 방법 |
| 2 | {K1}, {K2}, {K3} | 법인세 신고, 납부, 가산세 |
| 3 | {연도}년 {K1}과 {K2} | 2026년 법인세 신고 기한과 납부 방법 |
| 4 | {K1}부터 {K2}까지 | 법인세 신고부터 납부까지 |
| 5 | {K1} 시 {K2} 주의사항 | 법인세 신고 시 가산세 주의사항 |
| 6 | {K1} 전 알아야 할 {K2} | 법인세 납부 전 알아야 할 감면 혜택 |
| 7 | {K1}과 {K2} 차이 | 법인세 중간예납과 확정신고 차이 |
| 8 | {K1}, 언제 어떻게? | 법인세 신고, 언제 어떻게? |
| 9 | {K1} 및 {K2} | 법인세 신고 방법 및 필요 서류 |
| 10 | {K1}할 때 {K2} 확인 | 법인세 신고할 때 세율 확인 |

### 패턴 선택 기준

```
시간 관련 (기한, 기간, 일정) → 패턴 3, 4
방법 관련 (방법, 절차, 신청) → 패턴 1, 9
비교 관련 (차이, 비교) → 패턴 7
주의 관련 (주의, 실수) → 패턴 5, 6
```

---

## 2단계: 키워드 4개 추출

### 규칙

```
1. 타이틀에서 핵심 키워드 추출
2. 모든 키워드에 시드 포함
3. 동의어 그룹 중복 금지
4. 키워드 = H2 매칭 가능해야 함
```

### 예시

```yaml
title: "법인세 신고 기한과 납부 방법"

keywords:
  - 법인세 신고 기한      ← 타이틀에서 추출
  - 법인세 납부 방법      ← 타이틀에서 추출
  - 법인세 신고 방법      ← 타이틀 단어 조합
  - 법인세 납부 기한      ← 타이틀 단어 조합
```

---

## 3단계: H2 생성 (키워드 + 질문)

### 핵심: 키워드 = H2 완벽 일치

```
H2 = 키워드 + 질문패턴
```

### 질문 패턴표

| 키워드 끝말 | 질문 패턴 |
|------------|----------|
| 절차, 방법 | ~은 어떻게 되나요? |
| 이자, 금액, 세율 | ~은 얼마인가요? |
| 기한, 기간, 시기 | ~은 언제인가요? |
| 기준, 조건, 자격 | ~은 어떻게 되나요? |
| 대상, 해당자 | ~은 어떻게 되나요? |
| 서류, 준비물 | ~은 무엇인가요? |
| 차이, 비교 | ~은 뭐가 다른가요? |
| 종류, 유형 | ~에는 뭐가 있나요? |
| 계산 | ~은 어떻게 하나요? |
| 감면, 혜택 | ~은 어떻게 받나요? |

### 질문 패턴 금지

```
❌ ~이란 무엇인가요?  → ✅ ~이란?
❌ ~에는 어떤 것들이 있나요? → ✅ ~에는 뭐가 있나요?
❌ 길고 어색한 질문 → ✅ 짧고 자연스러운 질문
```

### 예시

```yaml
keywords:
  - 법인세 신고 기한
  - 법인세 납부 방법
  - 법인세 신고 방법
  - 법인세 납부 기한

h2:
  - 법인세 신고 기한은 언제인가요?      ← 키워드1 + 질문
  - 법인세 납부 방법은 어떻게 되나요?   ← 키워드2 + 질문
  - 법인세 신고 방법은 어떻게 되나요?   ← 키워드3 + 질문
  - 법인세 납부 기한은 언제인가요?      ← 키워드4 + 질문
```

## 4단계: 동의어 금지 그룹

**같은 타이틀/키워드 세트 내 1개만 사용**

```
그룹1: 자격 = 조건 = 요건
그룹2: 방법 = 절차 = 안내 = 하는 법
그룹3: 계산 = 산정 = 산출
그룹4: 확인 = 조회 = 검색
그룹5: 기간 = 기한 (문맥에 따라 허용)
그룹6: 비용 = 수임료 = 금액 = 가격
그룹7: 서류 = 준비물 = 문서 = 첨부
그룹8: 신청 = 접수 = 제출
그룹9: 대상 = 자격자 = 해당자
그룹10: 혜택 = 감면 = 공제
그룹11: 종류 = 유형 = 분류
그룹12: 기준 = 기초 = 표준
```

**위반 예시:**
```
❌ 법인세 신고 절차 + 법인세 납부 방법  (절차=방법, 그룹2)
❌ 법인세 신고 조건 + 법인세 납부 자격  (조건=자격, 그룹1)
✅ 법인세 신고 기한 + 법인세 납부 방법  (OK)
```

---

## 5단계: 중복 검사

### 검사 항목

```
□ 타이틀 중복 (기존 글과 80% 이상 유사)
□ 키워드 중복 (동일 키워드 이미 존재)
□ 동의어 그룹 위반
□ 키워드 ↔ H2 불일치
```

### 중복 발견 시

```
1. 해당 항목 재생성
2. 다른 패턴으로 타이틀 변경
3. 키워드 조합 변경
```
