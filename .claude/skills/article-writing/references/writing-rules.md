# 글쓰기 규칙

## 문체

구어체 필수: "~해요", "~이에요", "~예요", "~거든요"
"~합니다", "~입니다" 사용하지 않는다. metaDescription만 문어체 허용.

## 도입부 구조: 감정→행동 전환

도입부는 위키 사전식이 아니라, 사용자의 감정을 잡고 행동으로 이끄는 구조로 쓴다.

```
1문장: 사용자 상황 공감 (감정 건드리기)
2문장: 핵심 사실 (숫자 또는 법적 근거)
3문장: 행동 유도 ("지금 바로 확인해보세요")
→ 상황분기배너 진입
```

좋은 예 (양육비):
"모르면 그냥 넘어가는 돈이에요.
상대방이 안 줘도, 법이 강제할 수 있어요. 안 주면 구치소까지 가거든요.
내가 얼마 받을 수 있는지, 어떻게 받는지 지금 바로 확인해보세요."

나쁜 예:
"햇살론유스는 청년을 위한 저금리 서민금융입니다."

## 섹션 텍스트 공식

매 H2 섹션은 이 순서를 밟는다:

```
1문장: [상황] 독자가 지금 처한 상황 또는 궁금증
2문장: [결론] 이 소제목의 답을 바로 줌
3~5문장: [근거] 조건, 구조, 이유
[컴포넌트]
1~2문장: [행동] 다음 섹션 궁금증 열기
```

## 접속사 규칙

같은 접속사 2회 연속 사용하지 않는다.
같은 유형 접속사 3회 연속 사용하지 않는다.
접속사 없이 자연스럽게 이어지면 생략이 최선이다.
"또한", "아울러", "한편" → 사용하지 않는다 (AI 냄새).

## 어미 규칙

3문장 연속 같은 어미 사용하지 않는다.
풀: ~이에요/~예요(사실), ~이죠/~죠(확인), ~거든요(이유), ~있고요(나열), ~돼요(가능), ~봐요(권유)

## 문장 리듬

3문장 연속 같은 길이 사용하지 않는다.
패턴: 긴(20자+) → 짧(15자 이내) → 중간

## 섹션 마지막 문장

닫힌 마무리("기억하세요", "확인하세요")가 아니라 다음 섹션 궁금증을 여는 문장으로 끝낸다.
- 나쁜 예: "이 점을 꼭 기억해 두세요."
- 좋은 예: "금액이 얼마냐가 문제죠."

## 금지 표현

- "이 글에서는 ~에 대해 알아볼게요" (filler)
- "이렇게 하면 도움이 돼요" (빈 문장)
- "전문가와 상담하세요" → 어디서, 무료인지, 번호까지 명시
- "정확한 금액은 개인마다 달라요" → 어떤 변수가 금액을 바꾸는지 명시
- "총정리", "완벽정리", "다양한", "매우 중요" (AI 냄새)
