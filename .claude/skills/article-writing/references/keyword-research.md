# 키워드 리서치 상세 절차

## 1. 검색 의도 조사

WebSearch로 아래 3가지를 조사한다:

```
검색어 1: "[메인 키워드]" → 상위 5개 결과의 H1/H2 구조 확인
검색어 2: "[메인 키워드] 방법/조건/자격/계산" → 연관 키워드 수집
검색어 3: "[메인 키워드] site:kin.naver.com" → 실제 사용자 질문 수집
```

## 2. 키워드 클러스터 구성

수집한 키워드를 아래 분류로 나눈다:

| 분류 | 용도 | 예시 (햇살론유스) |
|------|------|----------------|
| 핵심 키워드 | H1 line1 | 청년 대출 조건, 대학생 저금리 대출 |
| 행동 키워드 | H1 line2 | 자격부터 신청까지, 계산법 |
| 롱테일 질문 | H2 | 나도 받을 수 있을까?, 얼마나 빌려야 할까? |
| FAQ 키워드 | FAQ 질문 | 신용 낮아도 되나요?, 금리 몇 프로? |
| 내부링크 키워드 | 사이드바/허브 | 서민금융 비교, 대출 갈아타기 |

## 3. H1 타이틀 생성

**공식**: [핵심 키워드 + 사용자 질문]? + [행동 키워드]

| 의도 유형 | 신호 | H1 패턴 |
|-----------|------|---------|
| 얼마형 | ~얼마, ~계산, ~금액 | "[주제], 얼마나 받을/내야 할까? [계산법부터 ~까지]" |
| 가능형 | ~할 수 있나, ~되나요 | "[대상]도 [행동] 가능할까? [자격 조건과 신청 방법]" |
| 방법형 | ~방법, ~어떻게, ~절차 | "[주제], 어떻게 하면 될까? [절차부터 ~까지]" |
| 비교형 | ~vs, ~차이, ~어떤 게 | "[A] vs [B], 뭐가 나을까? [조건별 비교]" |

**금지**: "총정리", "완벽정리", "A to Z", 40자 초과, 브랜드명만 단독 사용

## 4. H2 소제목 생성

H2 = 사용자 질문형. H2만 훑어봐도 "다 있네" 느껴야 한다.

| 패턴 | 예시 |
|------|------|
| 질문형 | "나도 받을 수 있을까?" |
| 금액형 | "한도 1,200만원, 얼마나 빌려야 할까?" |
| 행동형 | "신청하면 며칠 만에 입금돼요?" |
| 경고형 | "부결되면 어떻게 해야 할까?" |
| 비교형 | "일반 햇살론이랑 뭐가 다를까?" |

**금지**: "대상자 및 조건", "한도와 금리" 같은 사전식 제목
