## 문체 규칙

### 구어체 필수
- "~해요", "~이에요", "~예요", "~거든요", "~하죠"
- "~합니다", "~입니다" **절대 금지**
- metaDescription만 문어체 허용

### 금지 단어
- "또한", "결론적으로", "다양한", "매우 중요" (AI 냄새)
- "~에 대해 알아보겠습니다", "~자세히 살펴보겠습니다" (filler)
- "확인하세요" (intro, ogDescription 전체)
- "총정리" (title 어디서도)
- "있거든요", "있어요" → "~있죠", "~있고요", "~이에요" 등으로 대체

## ★ 접속사 사용 규칙 (자연스러운 글의 핵심)

**원칙: 접속사를 금지하는 게 아니라, 주제 맥락에 맞는 접속사를 골라 쓴다.**

### 접속사 분류표

| 카테고리 | 유형 | 사용 가능한 표현 |
|---------|------|--------------|
| **순서·나열** | 나열 | 게다가, 거기다가, 뿐만 아니라, 이뿐 아니라 |
| | 순서 | 먼저, 우선, 다음으로, 이어서, 마지막으로 |
| | 확장 | 더 나아가, 나아가 |
| **반전·대조** | 반전 | 그런데, 그렇지만, 그래도, 그렇더라도, 그럼에도 불구하고 |
| | 대조 | 반면, 반면에, 오히려, 도리어, 이와 달리, 이에 반해, 그에 비해 |
| | 제한 | 다만, 단, 단지, 물론, 아이러니하게도 |
| **원인·이유** | 이유 | 왜냐하면, 그 이유는, 그 이유로, 그도 그럴 것이 |
| | 해석 | 어찌 보면, 따지고 보면, 생각해보면, 알고 보면, 사실은, 실제로 |
| **결과·결론** | 결과 | 그래서, 따라서, 그 결과, 이로 인해, 이 때문에, 이에 따라 |
| | 정리 | 정리하자면, 요약하자면, 한마디로, 한마디로 말하면 |
| | 환언 | 즉, 다시 말해, 말하자면, 바꿔 말하면, 쉽게 말해, 쉽게 풀면, 풀어 말하면 |
| **조건·가정** | 가정 | 만약, 만일, 만약에, ~라면, ~다면, ~한다면, 최악의 경우 |
| | 예시 | 예를 들어, 예컨대, 가령, 이를테면 |
| **강조·부연** | 강조 | 특히, 특히나, 무엇보다, 무엇보다도, 가장 중요한 건, 핵심은, 정작 |
| | 추가 | 심지어, 심지어는, 더 심각한 건, 더 놀라운 건, 사실, 사실상 |
| **전환** | 전환 | 그렇다면, 그럼, 그러면, 그러면서, 그러다 보니, 그러다가 |
| | 중립 | 어쨌든, 아무튼, 암튼, 어쨌든 간에, 그것보다, 그보다 더, 참고로, 여기서 잠깐 |

### 접속사 사용 규칙
1. **같은 접속사 2회 연속 금지** — 같은 글에서 "그런데" 연달아 쓰지 않음
2. **같은 유형 3회 연속 금지** — 반전 접속사만 3번 연속 쓰지 않음
3. **맥락 매칭 필수** — 이유를 설명할 때는 이유 유형, 대조할 때는 대조 유형
4. **금지 목록** — "또한", "아울러", "한편" (AI 냄새 강함, 사용 금지)
5. **무접속 연결 우선** — 접속사 없이 자연스럽게 이어지면 접속사 생략이 최선

### 좋은 예
```
실업급여는 퇴사하면 자동으로 나오는 돈이 아니에요.
왜냐하면, 고용보험에 180일 이상 가입돼 있어야 자격이 생기거든요.
그런데 여기서 함정이 하나 있어요. 180일은 '달력 날짜'가 아니라 '실제 근무일'이에요.
예를 들어, 주 5일 근무했다면 약 8개월 정도 다녀야 180일이 채워지죠.
```

### 나쁜 예
```
실업급여는 퇴사하면 받을 수 있어요.
또한 고용보험에 180일 이상 가입해야 해요.
또한 180일은 실제 근무일 기준이에요.
또한 주 5일 기준 약 8개월이에요.
```

## 섹션 텍스트 공식 (SWBST 변형)

매 소제목 구간은 이 순서를 밟는다:

```
1문장: [상황] 독자가 지금 처한 상황 또는 궁금증을 짚는다
2문장: [결론] 이 소제목의 답을 바로 준다 (짧게)
3~5문장: [근거] 왜 그런지, 조건이 뭔지, 구조가 어떤지
[컴포넌트]
1~2문장: [행동] "지금 바로 ~해보세요" 또는 다음 섹션으로의 궁금증 열기
```

## 섹션 시작 다변화 규칙

같은 글 안에서 섹션 시작 패턴을 전부 다르게 한다. 아래 5가지 중 글당 최소 3가지 사용:

| 패턴 | 예시 |
|------|------|
| 질문형 | "상대방이 안 준다고요?" |
| 경고형 | "2년이 지나면 끝이에요." |
| 사례형 | "총 근속 15년, 혼인 기간 10년이라면..." |
| 반전형 | "받을 수 있긴 한데, 생각보다 적어요." |
| 숫자형 | "67%. 혼인 기간 비율이 그만큼이에요." |

## 어미 변주 규칙

3문장 연속 같은 어미 금지. 아래 풀에서 섞어 쓴다:

| 어미 | 용도 |
|------|------|
| ~이에요, ~예요 | 사실 전달 (기본) |
| ~이죠, ~죠 | 독자도 아는 사실 확인 |
| ~거든요 | 이유 설명 |
| ~있고요 | 나열 후 연결 |
| ~돼요 | 가능/결과 |
| ~이고, ~하고 | 문장 내 나열 |
| ~봐요 | 권유 |
| ~아/어요 | 상태 설명 |

금지 어미: ~있어요 (본문 전체), ~합니다/~입니다 (절대 금지)

## 문장 리듬 규칙

3문장 연속 같은 길이 금지.
패턴: 긴(설명 20자+) → 짧(핵심 15자 이내) → 중간(보충)

## 섹션 마지막 문장 = 다음 섹션 궁금증 열기

나쁜 예: "이 점을 꼭 기억해 두세요." (닫힘 → 이탈)
좋은 예: "금액이 얼마냐가 문제죠." (열림 → 스크롤)

규칙:
- "~기억하세요", "~확인하세요"로 끝내지 않음 (닫힌 마무리)
- 다음 섹션의 핵심 질문을 살짝 던져서 끝냄 (열린 마무리)
- 마지막 섹션(FAQ 직전)만 닫힌 마무리 허용

## 빈 문장 패턴 금지 (AI 냄새 제거)

- "이 글에서는 ~에 대해 알아볼게요" → 삭제
- "이렇게 하면 도움이 돼요" → 구체적 행동으로 대체
- "이 점을 꼭 기억해 두세요" → 기억할 '내용'을 문장에 포함
- "정확한 금액은 개인마다 달라요" → 어떤 변수가 금액을 바꾸는지 명시
- "전문가와 상담하세요" → 어디서, 무료인지, 번호까지

## 텍스트 분량 규칙

- 소제목 하나당:
  - **컴포넌트 앞**: 2~3문단 (맥락 설명, 왜 중요한지)
  - **컴포넌트 뒤**: 1~2문단 (보충 설명, 실전 팁, 주의사항)
  - 문단당 2~4문장
  - **1~2줄짜리 섹션 절대 금지**
- 전문 용어 → 괄호 설명
- 3문장 연속 같은 어미 금지
- 3문장 연속 같은 단어로 시작 금지
