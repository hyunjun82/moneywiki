## 본문 H2 4개 (키워드=타이틀=소제목 일치)

```markdown
## 퇴직금 지연이자는 얼마나 되나요?

**퇴직금 지급이 14일을 넘으면 연 20% 이자가 자동으로 발생해요.**

[근로기준법 제36조](https://www.law.go.kr/법령/근로기준법/제36조)에서 퇴직금은 퇴직일로부터 14일 이내에 지급하도록 정했어요.
이 기한을 넘기면 15일째부터 연 20%의 지연이자가 붙어요.

> 14일 = 법정 지급기한. 하루라도 넘기면 연 20% 이자 자동 발생.

실제로 퇴직금 1,000만원을 30일 늦게 받으면 약 16만원의 이자를 추가로 받을 수 있어요.
회사가 합의로 기한을 연장하자고 해도 법정 14일이 지나면 무조건 이자가 발생해요.
[퇴직금 지급 청구 방법](/w/퇴직금-지급-청구-방법)도 함께 확인하세요.


## 퇴직금 지연이자 청구는 어떻게 하나요?

**민사소송을 통해 법원에 청구해야 해요.**

그렇다면 노동청에 신고하면 되지 않나 싶겠지만, 지연이자는 형사처벌 대상이 아니라서 처리가 안 돼요.
원금인 퇴직금은 [노동청 진정](/w/퇴직금-노동청-신고)으로 받을 수 있지만, 지연이자는 별도로 민사소송을 해야 해요.

| 구분 | 퇴직금 원금 | 지연이자 |
|------|-----------|---------|
| 청구 방법 | 노동청 진정 | 민사소송 |
| 형사처벌 | 가능 | 불가 |
| 소멸시효 | 퇴직일부터 3년 | 지급일부터 3년 |

소송비용은 청구 금액에 따라 다르지만, 보통 인지대와 송달료 합쳐서 10~20만원 정도예요.
여기서 중요한 건 증거 준비예요. 퇴직증명서와 실제 입금일을 보여주는 통장 사본이 꼭 필요해요.


## 퇴직금 이자율 계산은 어떻게 하나요?

**연 20%를 365일로 나눠서 일할 계산해요.**

구체적으로 보면 이래요. 퇴직금 원금 x (20% / 365일) x 지연 일수가 공식이에요.
이렇게 하면 일 이자율이 0.0548%가 되는 거예요.

그러니까 퇴직금 1,000만원을 60일 늦게 받으면 약 32만 9천원의 이자가 생기는 셈이에요.
아직 퇴직금 원금을 모르신다면 [퇴직금 계산기](/w/퇴직금-계산기)에서 먼저 확인하세요.


## 퇴직금 청구 방법은 어떤 순서로 하나요?

**15일째부터 실제 지급일까지의 이자를 모두 받을 수 있어요.**

먼저 퇴직일로부터 14일까지는 정상 지급 기한이에요.
그 기한이 지나면 15일째부터 실제로 퇴직금을 받은 날까지가 지연 일수가 돼요.

한 가지 더 알아두실 게 있어요. 퇴직금에는 3년 소멸시효가 있지만, 지연이자는 퇴직금을 받은 시점부터 별도로 3년이 적용돼요.
회사와 합의서를 쓸 때도 [지연이자](/w/퇴직금-지연이자-받기) 포기 조항이 있는지 꼭 확인하세요.
```

## 단락 연결 (자연스러운 흐름)

연결어를 매번 같은 걸 쓰면 로봇 같아 보여요.
상황에 맞게 골라 쓰되, 한 글에서 같은 표현 반복 금지.

```
도입/전환:
  "그렇다면 ~ 싶겠지만"
  "여기서 중요한 건"
  "한 가지 더 알아두실 게 있어요"
  "그러니까 정리하면"
  "아직 ~ 모르신다면"
  "구체적으로 보면 이래요"
  "먼저 ~ 그 다음에"
  "자, 그러면"

강조/부연:
  "쉽게 말하면"
  "~ 라는 뜻이에요"
  "~ 하는 셈이에요"
  "다시 말해"
  "핵심은 이거예요"

주의/경고:
  "다만 주의할 점이 있어요"
  "여기서 실수하면"
  "놓치기 쉬운 부분인데"
  "많이들 헷갈리시는 게"

예시 전환:
  "예를 들어"
  "실제로 보면"
  "구체적인 숫자로 보면"
  "00씨 사례를 보면"

독자 질문 전환 (섹션 넘길 때):
  "그러면 기존 제도와 뭐가 다를까요?"
  "그렇다면 지금 신청하는 게 나을까요?"
  "그런데 서류는 뭐가 필요할까요?"
  "여기서 한 가지 궁금한 게 생기죠."
```

## 본문 시각 요소 (테이블/불릿/blockquote)

### 비교 테이블 (텍스트 먼저 → 테이블 뒤에!)

비교형 콘텐츠에서 테이블만 덜렁 놓지 않기.
먼저 텍스트로 핵심 차이를 설명하고, 그 뒤에 테이블로 정리.

```markdown
퇴직금은 일시금으로 한 번에 받는 거예요.
퇴직연금은 매달 나눠서 받을 수 있고, 운용 방식에 따라 수익이 달라져요.

| 구분 | 퇴직금 | 퇴직연금 |
|------|--------|----------|
| 수령 방식 | 일시금 | 연금 또는 일시금 |
| 운용 주체 | 회사 | 근로자 또는 회사 |
| 중간정산 | 제한적 가능 | IRP 이체 |
| 세금 혜택 | 퇴직소득세 | 연금소득세 (더 유리) |
```

### 서류/준비물 테이블 (구분 + 설명)

서류가 3개 이상이면 테이블이 불릿보다 가독성 좋음.

```markdown
| 서류 | 설명 |
|------|------|
| 퇴직증명서 | 회사에서 발급. 퇴직일과 근속기간 확인용 |
| 통장 사본 | 실제 입금일 확인. 지연일수 계산 증거 |
| 진정서 | 노동청 방문 시 작성. 양식은 현장 제공 |
```

### 선택 분기 불릿 (독자가 자기 상황 찾기)

비교/선택형 콘텐츠 마지막에 배치. "나는 어디?"를 바로 찾게.

```markdown
**나한테 맞는 건 뭘까요?**

- 빨리 목돈이 필요하다면 → [퇴직금 일시금 수령](/w/퇴직금-일시금)이 유리해요
- 노후 대비가 목적이라면 → [퇴직연금 IRP](/w/퇴직연금-irp)로 이체하는 게 나아요
- 세금을 아끼고 싶다면 → 연금 수령이 퇴직소득세보다 세율이 낮아요
```

### 순서/절차 번호 리스트

```markdown
1. 노동청에 방문해서 진정서를 작성해요
2. 담당 근로감독관이 회사에 조사를 나가요
3. 조사 결과에 따라 시정 명령이 내려져요
4. 회사가 안 따르면 검찰에 송치돼요
```

### blockquote 핵심 강조

섹션 시작이나 중요 포인트에서 독자 시선을 잡을 때.

```markdown
> 퇴직금은 퇴직일로부터 14일 안에 받아야 해요. 하루라도 늦으면 연 20% 이자가 붙어요.

이 14일이라는 기한은 [근로기준법 제36조](https://www.law.go.kr/법령/근로기준법/제36조)에서 정한 거예요.
```

### 조건별 분기 (금액/상황에 따라 다를 때)

같은 주제라도 조건에 따라 서류나 절차가 달라지면 분리.

```markdown
**의료비 10만원 이하라면**

진료비 영수증과 처방전만 있으면 돼요.
보험사 앱에서 사진 찍어 올리면 3일 안에 입금돼요.

**의료비 10만원 초과라면**

위 서류에 추가로 진단서가 필요해요.
보험사마다 요구하는 서류가 다르니 콜센터에 먼저 확인하세요.
```
