## 타이틀 황금 규칙

```
"[메인 롱테일 키워드] | [연관 롱테일 키워드]"  60자 이내

원칙 1) 양쪽 다 키워드. 한쪽이 문장이면 FAIL

원칙 3) 포털 실제 검색어에서 추출

BAD:  "퇴직연금 국채 | 어떻게 투자하나요?"  <- 오른쪽 질문형!
금지: 총정리, 완벽정리, 가이드, 구분자 -- : -
```

### description 규칙

```
글자수: 100~150자 (구글 meta description 최대 155자)
키워드: 4개 중 최소 3개 자연 포함
구조: 2문장 (호기심 유발 + 해결 제시)
문체: ~요체 (이에요/해요/드려요)
금지: "~알아봅니다", "~총정리", 키워드 나열, "확인하세요"
```

3가지 패턴 순환 (같은 허브 내 중복 금지):
- **A. 놀라움형**: "[사실]~라는 거 아시나요? [키워드 배치] 알려드려요"
- **B. 문제해결형**: "[고민] 고민이시죠? [키워드 배치] 방법을 알려드려요"
- **C. 숫자형**: "[숫자]~라는 사실, 알고 계셨나요? [키워드 배치] 정리해드려요"

### checker 규칙 (모든 글 필수)

- 모든 MD 글에 checker frontmatter 필수. 서론 바로 뒤 1번 섹션으로 렌더링
- groups: 2~3개 질문, 각 3~5개 선택지
- results: when 조건별로 pass/fail + headline + detail + badges + links
- default: 아무것도 선택 안 했을 때 안내
- 체커 렌더링 위치: 서론과 H2 사이 (자동)

## 서론 패턴

```markdown
*"독자가 실제로 검색할 때 머릿속에 떠오를 질문 (이탤릭)"*

본문 첫 문단: 핵심 사실 또는 상황 설명 (2~3문장, 구체적 숫자 포함)

브릿지 문장: 왜 이 글을 읽어야 하는지 (1문장)
동행 톤: "정리했어요" / "알려드릴게요" (명령형 CTA 금지)
```

### 서론 예시 (실제 사용)

```markdown
*"퇴직연금 수익률이 2%대라는데, 국채로 바꾸면 뭐가 달라지는 거야?"*

올해 9월, 퇴직연금 계좌 안에서 국채를 직접 살 수 있는 길이 열려요. 재정경제부는 2월 12일 '연금형 개인투자용 국채 추진협의체' 제1차 회의를 열고 제도 준비 상황을 점검했어요. 일반 국민이 퇴직연금으로 개인투자용 국채에 접근하는 건 이번이 처음이에요.

가산금리 확대에 세제혜택까지 겹치면서 기존 원리금보장형 상품과 구조적 차이가 확 벌어졌어요.
정부 공식 발표 자료만 가지고 정리했어요.
```

### 서론 줄별 역할

| 줄 | 역할 | 예시 |
|----|------|------|
| 1줄 (이탤릭) | 독자 실제 검색 질문 | *"퇴직연금 수익률이 2%대라는데..."* |
| 2~3줄 | 핵심 사실 + 숫자 | "올해 9월부터 가능, 재정경제부 발표" |
| 4줄 | 왜 중요한지 | "구조적 차이가 확 벌어졌어요" |
| 5줄 | 동행 톤 마무리 | "정부 공식 자료만 가지고 정리했어요" |

**금지**: "확인해 보세요", "알아보겠습니다", 명령형 CTA

## bridge-card (섹션 간 연결)

H2 섹션 끝에서 다음 관련 콘텐츠로 유도하는 카드.
글 1개에 1~2개 사용 (과다 금지).
전체 `<a>` 태그가 클릭 영역 (full-area clickable).

```html
<a href="/w/관련-슬러그" class="bridge-card">
  <p class="bridge-headline">독자가 궁금해할 자연스러운 질문?</p>
  <p class="bridge-body">
    핵심 사실 1~2문장.
    <strong>볼드로 핵심 강조</strong>.
    부연 설명 1문장.
  </p>
  <span class="bridge-btn">도착 페이지 주제 + 행동 동사 -></span>
</a>
```

### bridge-card 규칙

- `bridge-headline`: 독자 궁금증 (기계적 질문 반복 금지)
- `bridge-body`: 숫자/사실로 힌트 (2~3문장)
- `bridge-btn`: 도착 페이지 주제 + 동사 ("내 급여 기준 실질 수익률 대조 ->")
- **금지 buttonText**: "자세히 보기 ->", "전체 가이드 ->", "바로가기 ->", "확인하세요 ->"

## mark 태그 (선택적 하이라이트)

글 전체에서 **3~4곳만** 사용. 독자가 스크롤하면서 시선이 멈추는 핵심 숫자/사실에만.

```markdown
이 중에서 국채를 살 수 있는 건 <mark>**DC형과 IRP만**</mark>이에요.

가산금리가 <mark><strong>10년물 100bp(1.0%p), 20년물 125bp(1.25%p)</strong></mark>로 대폭 확대됐어요.

총급여 5,500만 원 이하면 <mark>**16.5%**</mark>, 초과하면 <mark><strong>13.2%</strong></mark>예요.
```

**금지**: 문단마다 mark, 문장 전체 mark, 5개 이상 mark

## 본문 시각 요소

### 비교 테이블 (텍스트 먼저 -> 테이블 뒤에!)

테이블만 덜렁 놓지 않기. 먼저 텍스트로 핵심 차이를 설명하고, 그 뒤에 테이블로 정리.
테이블 위에 H3 또는 H4 제목 필수.

```markdown
### 전용계좌와 퇴직연금 계좌 비교

전용계좌는 이자소득 분리과세(15.4%)가 적용되고, 퇴직연금 계좌는 3단계 구조예요.

| 항목 | 전용계좌 | 퇴직연금 계좌 |
|------|---------|-------------|
| ... | ... | ... |
```

### 서류/준비물 테이블

```markdown
| 서류 | 설명 |
|------|------|
| 퇴직증명서 | 회사에서 발급. 퇴직일과 근속기간 확인용 |
| 통장 사본 | 실제 입금일 확인. 지연일수 계산 증거 |
```

### blockquote 핵심 강조

섹션 시작이나 중요 포인트에서 시선 잡기.

```markdown
> 쉽게 말해, **국가가 원금과 이자를 보장하는 장기 저축 상품**이에요.
```

### 선택 분기 불릿 (나에게 맞는 건?)

비교/선택형 콘텐츠 마지막에 배치. 내부링크와 함께.

```markdown
**나한테 맞는 건 뭘까요?**

- 단기 투자가 목적이라면 -> [전용계좌 3*5년물](/w/개인투자용-국채-전용계좌)이 맞아요
- 세액공제까지 받고 싶다면 -> 퇴직연금 계좌 10*20년물 (이 글)
- 아직 IRP가 없다면 -> [IRP 개설 방법](/w/irp-개설-방법)부터 보세요
```

### 오해/Q&A blockquote (자주 헷갈리는 것)

```markdown
### 많이 오해하시는 부분

> **"DB형이면 국채 못 산다"** -> IRP를 별도로 개설하면 본인 납입분으로 매입 가능해요.
>
> **"국채 사면 돈이 20년 묶인다"** -> 매입 1년 후부터 중도환매 가능해요.
>
> **"전용계좌 분리과세랑 똑같은 거 아냐?"** -> 완전히 다른 체계예요.
```

### 단계별 설명 (볼드 번호)

순서가 있는 절차를 본문 흐름 안에서 설명할 때.

```markdown
**1단계: 세액공제 (납입할 때)**

IRP에 돈을 넣으면 연말정산에서 세금을 돌려받아요.

**2단계: 과세이연 (운용하는 동안)**

세금을 바로 내지 않아요. 나중에 연금으로 수령할 때까지 유예돼요.

**3단계: 연금 분리과세 (수령할 때)**

55세 이후에 연금 형태로 받으면 3.3~5.5%만 세금을 내요.
```

## ext-btn (외부 딥링크 버튼)

본문 마지막 H2 뒤, 출처 섹션 앞에 배치.
**행동 키워드가 있는 주제에만** 사용 (정보 전달형에는 불필요).

```html
<!-- 정부/공식 (검정) -->
<a href="딥링크URL" target="_blank" rel="noopener noreferrer" class="ext-btn ext-btn-black">
  <span class="ext-btn-badge">기관명 공식</span>
  <span class="ext-btn-text">서비스명</span>
  <span class="ext-btn-cta">바로가기 -></span>
</a>

<!-- 신청/조회 (파랑) -->
<a href="딥링크URL" target="_blank" rel="noopener noreferrer" class="ext-btn ext-btn-blue">
  <span class="ext-btn-badge">무료 조회</span>
  <span class="ext-btn-text">서비스명</span>
  <span class="ext-btn-cta">조회하기 -></span>
</a>

<!-- 다운로드/양식 (초록) -->
<a href="딥링크URL" target="_blank" rel="noopener noreferrer" class="ext-btn ext-btn-green">
  <span class="ext-btn-badge">무료 다운로드</span>
  <span class="ext-btn-text">양식명</span>
  <span class="ext-btn-cta">다운로드 -></span>
</a>
```

**행동 키워드 판단 기준**:
- 계산, 조회, 신청, 확인, 다운로드 -> ext-btn 사용
- "~란?", "~차이", "~비교" 등 정보 전달형 -> ext-btn 불필요

## 단락 연결 (전환 표현)

한 글에서 같은 표현 반복 금지. 상황에 맞게 골라 쓰기.

```
도입/전환:
  "그렇다면 ~ 싶겠지만"
  "여기서 중요한 건"
  "한 가지 더 알아두실 게 있어요"
  "그러니까 정리하면"
  "구체적으로 보면 이래요"
  "먼저 ~ 그 다음에"

강조/부연:
  "쉽게 말하면"
  "~ 라는 뜻이에요"
  "~ 하는 셈이에요"
  "핵심은 이거예요"

주의/경고:
  "다만 주의할 점이 있어요"
  "놓치기 쉬운 부분인데"
  "많이들 헷갈리시는 게"

예시 전환:
  "실제로 보면"
  "구체적인 숫자로 보면"
  "00씨 사례를 보면"

독자 질문 전환 (섹션 넘길 때):
  "그런데 왜 지금 이 상품이 주목받는 걸까요?"
  "그러면 실제로 내 돈을 넣었을 때 얼마나 차이가 나는지 궁금하죠?"
  "그렇다면 지금 신청하는 게 나을까요?"
  -> 글 전체에서 "그렇다면 X일까요?" 전환은 최대 1회
```

## 절대 금지 (위반 시 재작성)

| 금지 항목 | 이유 |
|----------|------|
| "예시 1, 2, 3" 순번 H3 | AI 티 |
| ~습니다/~합니다 | 관공서체 |
| "확인하세요" | 명령형 CTA |
| "총정리", "완벽정리" | 스팸 느낌 |
| title에 콜론(:), 긴대시(--) | 구분자 규칙 위반 |
| description 키워드 나열 | CTR 최악 |
| mark 5개+ | 과다 강조 |
| ext-btn (정보 전달형 글) | 클릭할 곳 없음 |
| `<div class="table-title">` | H3/H4 실제 헤딩 사용 |
| 섹션 2문장 이하 | 단락 너무 짧음 |
| 본문에 FAQ 섹션 | frontmatter만 |

## 5원칙 체크리스트

- [ ] **텍스트가 주인공**: 시각요소는 보조
- [ ] **구어체 필수**: ~이에요, ~해요 (~습니다/됩니다 절대 금지)
- [ ] **독자 중심**: 20~80세 누구나 이해 가능
- [ ] **섹션당 4문장 이상**: 단락이 짧으면 AI 티
- [ ] **FAQ는 frontmatter만**: 본문에 FAQ 섹션 금지
