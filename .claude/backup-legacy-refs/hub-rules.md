# 허브 작성 규칙서

> hub-writer.md와 중복되는 기본 규칙(title, description, 컴포넌트, 금지)은 여기 없음.
> 이 파일 = hub-writer.md에 없는 **상세 가이드 + 예문**.

---

## 1. 허브 요약 수준 — 스포크와 깊이 차이

허브는 "무엇인가" + "왜 중요한가" 수준. 스포크는 "어떻게" + "구체적으로 얼마" 수준.

```
허브: "개인파산 신청비용은 인지대와 예납금으로 구성돼요."
스포크: "인지대는 3만 원이에요. 예납금은 채권자 수에 따라 달라지는데, 
       채권자 10명 기준으로 약 50만~80만 원 수준이에요."
```

같은 문장을 허브와 스포크에 동시에 쓰면 카니발라이제이션 발생. 각 H2는 2~3단락으로 핵심만.

---

## 2. sectionSpoke + chips = 내부링크 (스포크 URL)

```
규칙:
1. sectionSpoke: 각 섹션 끝에 관련 스포크 1~4개
2. chips: hero 아래 4칸, 각각 다른 스포크로 이동
3. href는 /w/슬러그 형태만 (# 앵커 절대 금지)
4. 실존 슬러그만 (Glob 확인 필수)
5. 허브 → 자기 스포크만 대상 (다른 허브의 스포크 금지)
```

---

## 3. 본문 인라인 내부링크 (나무위키 방식)

본문에서 스포크 키워드가 자연스럽게 언급될 때 `<a href="/w/슬러그">키워드</a>` 연결.

```
- 허브당 최소 2개, 최대 5개
- 같은 슬러그 반복 링크 금지 — 첫 등장에만
- 자연스러운 문맥에서만 — 억지 삽입 금지
- 실존 슬러그만 (Glob 확인 필수)
```

## 4. 금지 표현 탐지 패턴

| # | 금지 | 이유 |
|---|------|------|
| 1 | ~습니다/~됩니다 | 문어체 |
| 2 | "알아보겠습니다" | 블로그 서두 |
| 3 | "많은 분들이" | 네이버 블로그체 |
| 4 | "이번 포스팅" | 블로그 지시어 |
| 5 | "살펴보겠습니다" | 문어체 전환 |
| 6 | "~란 무엇일까요?" | 의문형 서두 |
| 7 | "오늘은 ~해보려고" | 일기체 서두 |
| 8 | 5줄 이상 단락 | 허브는 간결하게 |
