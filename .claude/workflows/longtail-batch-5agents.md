## 🔍 검증 워크플로우 (자동)

### 1단계: 패턴 횟수 체크
```bash
# "예를 들어볼게요" 횟수 확인 (0-1회만 허용)
grep "예를 들어볼게요" content/wiki/*.md | wc -l

# 각 파일별 횟수 (2회 이상 = 위반!)
grep -c "예를 들어볼게요" content/wiki/파일명.md
```

### 2단계: 서론 길이 체크
```python
# Python으로 서론 추출 및 길이 체크
import re

def check_intro_length(file_path):
    with open(file_path, 'r', encoding='utf-8') as f:
        content = f.read()

    # frontmatter 이후, 첫 H2 이전 내용 추출
    intro = re.search(r'---\n.*?---\n\n(.*?)\n##', content, re.DOTALL)
    if intro:
        intro_text = intro.group(1).strip()
        length = len(intro_text)  # 공백 포함
        if length > 160:
            print(f"❌ {file_path}: {length}자 (160자 초과!)")
        else:
            print(f"✅ {file_path}: {length}자")
```

### 3단계: A씨 B씨 C씨 체크
```bash
# C씨 사용 검사 (있으면 위반!)
grep "C씨" content/wiki/*.md

# 결과: 0건이어야 함
```

### 4단계: "오늘은" 금지 패턴 체크
```bash
# 서론에 "오늘은" 사용 검사
grep "오늘은\|오늘\|지금부터" content/wiki/*.md

# 결과: 0건이어야 함
```

### 5단계: 종합 검증 스크립트
```bash
# scripts/validate-patterns.sh
#!/bin/bash

echo "=== 패턴 검증 시작 ==="

# 1. "예를 들어볼게요" 2회 이상 파일 찾기
echo "1. 패턴 중복 체크..."
for file in content/wiki/*.md; do
  count=$(grep -c "예를 들어볼게요" "$file" 2>/dev/null || echo 0)
  if [ "$count" -ge 2 ]; then
    echo "❌ $file: $count회 (1회 초과!)"
  fi
done

# 2. C씨 사용 체크
echo "2. C씨 사용 체크..."
grep -l "C씨" content/wiki/*.md 2>/dev/null && echo "❌ C씨 발견!" || echo "✅ C씨 없음"

# 3. "오늘은" 체크
echo "3. 금지 패턴 체크..."
grep -l "오늘은\|오늘\|지금부터" content/wiki/*.md 2>/dev/null && echo "❌ 금지 패턴 발견!" || echo "✅ 금지 패턴 없음"

echo "=== 검증 완료 ==="
```

## 📊 현실적 기대치

### 목표 준수율
```yaml
패턴_다양성: 80-90% (5개 에이전트 사전 할당으로)
수동_보정: 10-20% (자연스러운 흐름 위해 필요)
자동_검증: 100% (스크립트로 위반 체크)
```

### 왜 100% 완벽은 어려운가?
1. **에이전트는 독립적으로 작동** → 서로 패턴 모름
2. **자연스러운 흐름 > 완벽한 패턴 분배** → 때로는 같은 표현이 더 자연스러울 수도
3. **16개씩 작성하다 보면** → 무의식적 반복 가능

### 해결 방법
1. **사전 할당으로 80-90% 준수** (패턴 세트 A~E)
2. **검증 스크립트로 위반 자동 감지** (Grep, Python)
3. **10-20%는 수동 보정** (자연스러운 흐름 유지하며)
4. **우선순위**: 자연스러움 > 완벽한 다양성

### 실제 작업 플로우
```yaml
1. 5개 에이전트 병렬 실행 (패턴 세트 A~E 할당)
2. 검증 스크립트 실행 (자동 위반 체크)
3. 위반 파일만 수동 보정 (10-20%)
4. 최종 확인 후 배포

예상_시간: 1.5시간 (80개) + 20분 (보정) = 1시간 50분
품질: 80-90% 자동 준수 + 10-20% 수동 완성도 = 100%
```
