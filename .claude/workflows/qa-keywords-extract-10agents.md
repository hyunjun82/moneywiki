## ⚙️ 자동 설정

### 서브 에이전트 구성
```yaml
agents: 10개 병렬 실행
distribution: 자동 균등 분배 (164개 → 16-17개씩)
compression: --uc (토큰 절감)
model: sonnet (정확도)
task: 키워드 추출만 (본문 X)
```

### 출력 형식
```yaml

structure:
  - id: 번호
  - question: 원본 질문
  - title: 롱테일 제목
  - keywords: [4개 배열]
```

## 🔑 키워드 확장 핵심 원칙

### title 작성 규칙
- **title = keywords 조합**
- title의 모든 핵심 단어가 keywords에 포함되어야 함
- 예: "장애인 의무고용 100명 기준 비율" = "장애인 의무고용" + "100명" + "기준" + "비율"

### keywords 작성 규칙
1. **2단어 베이스** (힘들지만 사이트 점수 오르면 가능)
2. **3단어 롱테일** (검색 가능한 구체적 키워드)
3. **3단어 롱테일** (다른 측면의 구체적 키워드)
4. **4단어 풀 롱테일** (title과 거의 동일하거나 매우 구체적)

### 중복 제거 필수!
❌ **같은 의미 중복**:
- "신청" = "신청 방법"
- "확인" = "확인 방법"
- "조건" = "대상"
- "100명" = "100명 비율" (X)

✅ **서로 다른 의미**:
- "신청" ≠ "조건" (행위 vs 요건)
- "100명" ≠ "기준" (규모 vs 기준)
- "비율" ≠ "계산" (비율 vs 방법)
