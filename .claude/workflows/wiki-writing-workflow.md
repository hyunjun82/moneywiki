# 위키 글 작성 워크플로우

**목적**: 템플릿 위반 방지 + 자동 검증

---

## 🚨 필수 준수사항 (강제)

### wegive 3원칙
> **20~80대 누구나 이해** | **궁금증 100% 해결** | **다른 사이트 갈 필요 없음**

### 작성 전 필수 체크
```yaml
단계1: moneywiki-template.md 읽기 (필수!)
단계2: wegive-template-full.md 읽기 (필수!)
단계3: WebSearch [키워드] 2026 (최신 정보)
단계4: 글 작성
단계5: 자동 검증 → 통과/재작성
```

---

## ✅ 자동 검증 체크리스트

### 1. wegive 본질 검증
```yaml
□ 20~80대 이해 가능?
  - 전문용어 바로 풀이
  - 비유/예시 사용
  - 짧은 문장

□ 궁금증 100% 해결?
  - "뭔지" 정의
  - "왜" 이유
  - "어떻게" 방법
  - "주의사항" 함정

□ 다른 사이트 불필요?
  - 핵심 정보 모두 포함
  - 실제 예시 있음
  - 내부링크 3개 이상
```

### 2. 구조 검증
```yaml
□ Keywords 4개 = H2 4개?
□ 모든 H2에 베이스 키워드?
□ H2 PAA 질문형? (~, 뭐예요? / ~, 어떻게 해요?)
□ 각 섹션 4문장 이상? (6-10문장 권장)
□ 테이블 2개 이하?
```

### 3. Frontmatter 검증
```yaml
□ author: "머니위키 에디터"?
□ keywords 4-5개?
□ FAQ 2-3개? (소제목과 안 겹침)
□ summary 배열 3줄?
□ updateNote: "2026년 1월 기준"?
```

### 4. 문체 검증
```yaml
□ 구어체? (~이에요, ~해요, ~하죠)
□ 단답형 없음? ("돼요." → "네, 가능해요.")
□ 이모지 없음?
□ 숫자 헤딩 없음? (## 1. 제목 → ## 제목)
```

## ⛔ 재작성 트리거

**다음 중 1개라도 위반 시 전체 재작성**:

1. **섹션이 2-3문장만** → 4문장 이상 필수
2. **테이블 3개 이상** → 텍스트로 전환
3. **"왜?"에 대한 설명 없음** → 이유 추가
4. **Keywords ≠ H2** → 일치시키기
5. **H2에 베이스 키워드 없음** → 포함시키기
6. **전문용어 설명 없음** → 바로 풀이
7. **실제 예시 없음** → 구체적 상황 추가

## 📝 작성 프로세스

### 단계 1: 준비
```bash
1. moneywiki-template.md 읽기
2. wegive-template-full.md 읽기 (예시는 참고용, 복사 금지!)
3. WebSearch "[키워드] 2026" 실행
```

### 단계 2: 초안 작성
```yaml
서론: 160자 이내 (상황 공감 → 중요성 → 해결)
H2-1: [베이스], 뭐예요? (정의 + 왜 중요 + 실제 예시)
H2-2: [베이스 + 확장어1], 어떻게 해요? (방법 + 절차 + 주의사항)
H2-3: [베이스 + 확장어2], 얼마예요? (비용 + 계산법 + 예시)
H2-4: [베이스 + 확장어3], 주의할 점은요? (함정 + 해결법)
출처: 본문 인라인 + 하단 섹션
```

### 단계 3: 자동 검증
```yaml
체크리스트 35개 항목 전부 확인
→ 1개라도 실패 시 재작성
→ 전부 통과 시 배포
```

### 단계 4: 배포
```bash
git add content/wiki/[파일명].md
git commit -m "feat: [제목]"
git push origin main
```

## 🔍 검증 실패 예시

### ❌ 나쁜 예
```markdown
## 청년미래적금 가입조건

만 19~34세, 소득 6천만 원 이하면 가입 가능해요.
```
**문제점**:
- 2문장만 (4문장 미만)
- "왜 6천만 원인지" 설명 없음
- 실제 예시 없음

### ✅ 좋은 예
```markdown
## 청년미래적금 가입조건, 정확히 뭐예요?

가입하려면 4가지 조건을 모두 충족해야 해요. 하나라도 안 맞으면 가입이 안 되니까 꼭 확인하세요.

첫째, 나이는 만 19세~34세여야 해요. 병역 이행 기간이 있으면 그만큼 나이에서 빼줘요. 군대 2년 다녀왔으면 36세까지도 가입 가능하다는 뜻이에요. 주민등록상 생년월일 기준이에요.

둘째, 개인소득이 6,000만 원 이하여야 해요. 근로소득, 사업소득, 기타소득 다 합쳐서 6,000만 원이에요. 연봉으로 따지면 대략 7,000만 원 정도까지 가능해요. 전년도 소득 기준이에요.

(... 계속)
```
**좋은 점**:
- 8문장 이상 (충분한 설명)
- "왜?"에 대한 답변 (병역 이행 기간 빼줌, 연봉으로 환산)
- 실제 예시 (군대 2년, 연봉 7,000만 원)
- 독자 상황 고려 (주민등록, 전년도 소득)

## 🚀 최종 점검

작성 완료 후 다음 질문에 답하세요:

1. **"20살도, 80살도 이해할 수 있나요?"**
   - NO → 전문용어 풀이, 비유 추가

2. **"이 글 하나로 궁금증 해결되나요?"**
   - NO → "왜?" 설명 추가, 예시 추가

3. **"다른 사이트 갈 필요 없나요?"**
   - NO → 핵심 정보 추가, 내부링크 추가

**3개 모두 YES → 배포**
**1개라도 NO → 재작성**
