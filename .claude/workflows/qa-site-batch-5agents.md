> **생활법령정보 등 Q&A 사이트 전용**: 질문 + 답변 활용 → 웹검색 불필요 → 오차 0%

## ⚙️ 자동 설정

### 서브 에이전트 구성
```yaml
agents: 5개 병렬 실행
distribution: 자동 균등 분배 (100개 → 20개씩)
compression: --uc (30-50% 토큰 절감)
model: sonnet (정확도 우선)
web_search: 불필요 (Q&A 답변 활용)
```

### Q&A 활용 전략
```yaml
input:
  - 질문(Q): 롱테일 키워드로 확장
  - 답변(A): 본문 콘텐츠로 활용
output:
  - wegive-template-full.md 스타일
  - 2-3-3-4 단어 키워드 패턴
accuracy: 100% (정부기관 공식 답변)
```

## 🚀 실행 프로세스

### 1단계: Q&A 분배
```yaml
total_qa: 100개
agent_1: Q&A 1-20
agent_2: Q&A 21-40
agent_3: Q&A 41-60
agent_4: Q&A 61-80
agent_5: Q&A 81-100
```

### 2단계: 각 에이전트 작업
```yaml
1. 질문(Q) 읽기
2. 롱테일 키워드 확장 (2-3-3-4 단어)
3. 답변(A) 활용해서 본문 작성
4. wegive 스타일 적용
5. 내부링크 3개+ 추가
6. 출처 표기 (Q&A 사이트 URL)
```

### 3단계: 패턴 세트 할당

#### Agent 1 (1-20): 패턴 A
```yaml
예시_전환구: "예를 들어볼게요" (0-1회)
설명_시작: "쉽게 말하면"
```

#### Agent 2 (21-40): 패턴 B
```yaml
예시_전환구: "예를 들면" (0-1회)
설명_시작: "다시 말해"
```

#### Agent 3 (41-60): 패턴 C
```yaml
예시_전환구: "살펴보면" (0-1회)
설명_시작: "쉽게 말하면"
```

#### Agent 4 (61-80): 패턴 D
```yaml
예시_전환구: 전환구 없이 바로 예시
설명_시작: 바로 설명 (전환구 생략)
```

#### Agent 5 (81-100): 패턴 E
```yaml
예시_전환구: "구체적으로 보면" (0-1회)
설명_시작: "이해 쉽게 정리해보면"
```

## ⚠️ wegive 스타일 핵심 규칙

### 서론 작성
```yaml
길이: 공백 포함 160자 이내 (엄격!)
시작_금지: "오늘은", "오늘", "지금부터"
구성: 독자 공감 → 핵심 답변 (4-5문장)
```

**✅ 예시**:
```markdown
"전세 2년 살았는데 더 살고 싶어요. 집주인한테 어떻게 말해야 하죠?"

계약갱신청구권을 쓰면 돼요. 집주인이 거절 못하고, 월세/전세금 5% 제한돼요.
근데 타이밍 놓치면 권리 자체가 사라져요. (152자)
```

### A씨 B씨 예시
```yaml
최대_인원: 2명 (A씨, B씨만)
금지: C씨, D씨 절대 안 됨
횟수: 0-1회 (예시 전환구와 함께)
길이: 3줄 이내
```

### 독자 니즈 중심
```yaml
목표: "다른 곳 갈 필요 없음" 100% 해결
대상: 20~80대 누구나 이해 가능
원칙:
  - 핵심만 간결하게
  - 전문용어 바로 풀어서 설명
  - 실제 상황 예시 포함
```

## 📊 작업 예시

### 입력 (Q&A)
```
Q: 저는 상시근로자가 100명인 사업장의 사업주입니다.
   우리 사업장의 경우 장애인 고용의무를 준수해야 한다고 하는데
   최소 몇 명의 장애인근로자를 고용해야 하나요?

A: 2024년 기준 상시 50명 이상의 근로자를 고용한 민간기업 사업주는
   최소 근로자 수의 3.1%를 장애인근로자로 고용해야 합니다.
```

### 출력 (키워드 확장)
```yaml
title: 장애인 의무고용 100명 기준 비율
keywords:
  - 장애인 의무고용              # 2단어
  - 장애인 의무고용 100명        # 3단어
  - 장애인 의무고용 기준          # 3단어
  - 장애인 의무고용 100명 비율   # 4단어
```

### 출력 (본문)
```markdown
상시 근로자 100명 사업장이라면 몇 명의 장애인을 고용해야 할까요?

2024년 기준 상시 50명 이상 사업장은 3.1%를 장애인으로 고용해야 해요.
100명 × 3.1% = 3.1명이니까, 올림해서 최소 4명이에요.
```
