## ✅ 처리 방식

1. 각 파일의 frontmatter 읽기
2. Title을 제시된 패턴으로 변환 (중간점 · 사용)
3. Keywords를 정확히 5개로 확장 (베이스 반복)
4. Description 재작성 (~해요 패턴)
5. 본문 H2 섹션명 title 키워드 포함하도록 수정
6. 본문 내용은 변경 없음

## 🔍 검증 체크리스트

- [ ] Title에 중간점(·) 4개 사용 (5개 컴포넌트)

- [ ] 모든 keywords가 Base 포함

- [ ] Description ~해요 패턴
- [ ] FAQ 3개 유지
