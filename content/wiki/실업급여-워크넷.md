*"고용24, 워크넷, 고용센터... 다 비슷해 보이는데 뭐가 뭔지 모르겠어요."*

역할이 달라요. 워크넷은 취업 사이트고, 고용24는 고용보험 서비스 사이트예요. 실업급여를 받으려면 둘 다 사용해야 해요. [고용보험법 제42조](https://www.law.go.kr/법령/고용보험법)에 따라 구직신청(워크넷 등록)은 실업급여 신청의 첫 단계예요.

워크넷 구직등록은 <mark>**10~15분**</mark>이면 완료돼요. 이력서를 완벽하게 작성 안 해도 기본 정보만 넣으면 돼요. 정부 공식 기준으로 워크넷 구직등록 방법과 구직활동 연동 방법을 정리했어요.

## 실업급여 워크넷 구직등록은 왜 필요한가요?

**실업급여는 구직 의사가 있는 사람에게만 지급해요.** 워크넷 구직등록은 "일자리를 찾고 있다"는 걸 공식으로 등록하는 절차예요. 등록이 없으면 수급자격 신청 자체가 안 돼요.

워크넷은 고용노동부에서 운영하는 공식 취업 사이트예요. 채용정보 검색, 입사지원, 취업지원 서비스 등을 무료로 이용할 수 있어요. 민간 취업 사이트(잡코리아, 사람인 등)와 달리 정부 운영이라 신뢰도가 높아요.

워크넷과 고용24는 연동돼 있어요. 워크넷에서 입사지원하면 그 내역이 고용24 실업인정 시스템에 자동으로 연동돼요. 별도로 구직활동 내역을 다시 입력할 필요가 없어요. 이 연동 때문에 워크넷 활용이 실업급여 수급 중에 특히 편리해요.

## 실업급여 워크넷 구직등록 이력서 작성 방법은 뭔가요?

**5단계예요.** 회원가입 → 로그인 → 이력서 작성 → 구직 조건 입력 → 완료 순서예요.

| 단계 | 내용 |
|------|------|
| 1단계 | 워크넷(work.go.kr) 회원가입 (공동인증서 or 간편인증) |
| 2단계 | 로그인 후 구직등록 메뉴 선택 |
| 3단계 | 내 정보 입력 (이름, 연락처, 학력, 경력) |
| 4단계 | 희망 직종, 근무 조건, 희망 급여 입력 |
| 5단계 | 구직등록 완료 확인 및 확인증 출력 |

이력서는 최소 항목만 채워도 등록이 완료돼요. 기본 정보(이름, 연락처, 학력, 희망 직종)만 입력하면 돼요. 나중에 언제든 수정할 수 있어요. 구직등록 완료 후 확인증을 출력하면 고용센터 방문 시 지참할 수 있어요.

## 실업급여 워크넷 입사지원은 구직활동로 인정되나요?

**인정돼요.** 워크넷에서 입사지원하면 구직활동 1회로 자동 인정되고, 고용24 실업인정에 자동 연동돼요.

실업인정 주기는 보통 2~4주 단위예요. 이 기간에 구직활동 횟수 기준을 채워야 실업급여가 지급돼요. 워크넷 입사지원이 자동 연동되기 때문에 별도 증빙서류 첨부 없이 바로 인정돼요.

다른 채용사이트 지원이나 면접, 직업훈련도 구직활동으로 인정되지만 직접 입력해야 해요. 워크넷이 편한 이유는 이 자동 연동 기능 때문이에요. 수급 중에는 워크넷을 통해 지원하는 게 관리가 편해요.

## 실업급여 수급 중 워크넷을 더 잘 활용하는 방법은요?

**이력서 공개와 알림 설정을 해두면 좋아요.** 이력서 공개 설정을 하면 기업에서 먼저 연락이 오는 경우도 있어요. 관심 기업을 등록해두면 해당 기업 채용공고가 올라올 때 알림이 와요.

워크넷 앱을 설치하면 더 편해요. 앱스토어나 플레이스토어에서 "워크넷"을 검색해서 설치하면 돼요. 이동 중에도 채용공고 확인과 입사지원이 가능해요. 입사지원 후 고용24 실업인정에 바로 반영되는 것도 앱에서 확인할 수 있어요.

취업지원 서비스도 활용해 보세요. 워크넷에서 이력서 첨삭, 면접 코칭, 직업 훈련 프로그램 신청이 가능해요. 이런 프로그램 참여도 구직활동으로 인정되는 경우가 많아요.
