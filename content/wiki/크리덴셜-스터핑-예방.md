한 사이트에서 비밀번호가 유출되면 다른 사이트까지 전부 털릴 수 있다는 거 아시나요? 크리덴셜 스터핑 공격은 이미 유출된 계정 정보를 다른 사이트에 대입해서 로그인을 시도하는 수법이에요. 최근 GS리테일과 인터넷 강의 사이트에서만 18만 명이 넘는 피해가 발생했어요. 지금 바로 [털린 내 정보 찾기](/w/털린-내-정보-찾기)에서 내 계정 정보가 유출됐는지 확인하고 예방법을 알아보세요.

## 크리덴셜 스터핑은 무엇인가요?

**유출된 계정 정보를 자동화된 방식으로 여러 사이트에 대입해서 로그인을 시도하는 사이버 공격이에요.**

[크리덴셜 스터핑](https://asec.ahnlab.com/ko/87472/)은 이미 다크웹에 유출된 실제 사용자의 아이디와 비밀번호를 활용해요. 대부분의 사람들이 여러 사이트에서 같은 비밀번호를 쓴다는 점을 악용하는 거죠. 예를 들어 A 쇼핑몰에서 유출된 계정 정보를 B 은행, C 포털 사이트에 자동으로 대입해서 로그인을 시도해요. 무차별 대입 공격과 달리 이미 확보된 실제 계정 정보를 사용하기 때문에 성공률이 훨씬 높아요. 해킹 사고 유형 중 SQL Injection, 악성코드에 이어 세 번째로 많이 사용되는 공격 방식이에요.

## 크리덴셜 스터핑 공격을 어떻게 예방하나요?

**사이트마다 다른 비밀번호를 사용하고 2단계 인증을 설정하면 대부분의 공격을 막을 수 있어요.**

[SK쉴더스 보안 분석](https://www.skshieldus.com/blog-security/security-trend-idx-28)에 따르면 사이트별로 다른 비밀번호를 사용하면 유출 피해를 최소화할 수 있어요. 한 사이트에서 계정 정보가 유출되더라도 다른 사이트는 안전하거든요. 비밀번호 관리 앱을 사용하면 각 사이트마다 강력한 비밀번호를 자동으로 생성하고 저장할 수 있어서 편리해요. 주기적으로 비밀번호를 변경하는 것도 중요해요. 사이트에서 비밀번호 변경 알림이 오면 즉시 바꿔야 해요. [안전한 비밀번호 만들기](/w/안전한-비밀번호-만들기)에서 강력한 비밀번호 생성 방법을 확인하세요.

| 예방 방법 | 효과 | 실천 난이도 |
|----------|------|------------|
| 사이트별 다른 비밀번호 | 중간 (60% 차단) | 중간 (관리 앱 필요) |
| 주기적 비밀번호 변경 | 중간 (50% 차단) | 어려움 |
| 2단계 인증 (문자) | 높음 (85% 차단) | 쉬움 |
| 2단계 인증 (앱) | 매우 높음 (95% 차단) | 쉬움 |

## 계정 해킹을 차단하려면 어떻게 해야 하나요?

**2단계 인증을 설정하는 게 가장 효과적이에요.**

[2단계 인증](https://support.google.com/accounts/answer/185839)은 비밀번호 외에 추가 인증 단계를 거치는 방식이에요. 해커가 비밀번호를 알아도 인증 앱이나 문자 코드 없이는 로그인할 수 없어요. 아이디와 비밀번호를 탈취하는 건 쉽지만 2단계 인증 수단을 물리적으로 손에 넣는 건 거의 불가능하기 때문에 해커 입장에서는 2단계 인증에 막히면 해킹 자체를 포기하게 돼요. 문자(SMS)보다는 인증 앱(Google Authenticator, Microsoft Authenticator 등)이 더 안전하고 안정적이에요. 구글, 네이버, 카카오, 은행 앱 등 대부분의 주요 서비스에서 2단계 인증을 지원하니까 바로 설정하세요.

## 내 비밀번호가 유출됐는지 어떻게 확인하나요?

**개인정보보호위원회의 털린 내정보 찾기 서비스에서 무료로 확인할 수 있어요.**

[털린 내정보 찾기](https://kidc.eprivacy.go.kr/)에 접속해서 아이디·비밀번호나 이메일 주소를 입력하면 다크웹 유출 여부를 즉시 확인할 수 있어요. 국내 2,300만 건과 구글 40억 건의 데이터베이스를 검색해서 알려줘요. 유출 이력이 있으면 즉시 해당 비밀번호를 변경하고 같은 비밀번호를 쓰는 다른 사이트도 전부 바꿔야 해요. [털린 내 정보 이메일 조회](/w/털린-내-정보-이메일-조회)에서 이메일 주소만으로 조회하는 방법도 확인해보세요. 하루 3회까지 조회할 수 있으니까 자주 쓰는 계정 정보를 모두 확인하세요.
